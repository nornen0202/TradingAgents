성장 동력도 현재 제품에만 머물지 않습니다. Lilly가 9월 30일 발표한 레타트루타이드 3상 시험에서 12mg 투여군은 80주 동안 평균 최대 20.8%의 체중 감소와 당화혈색소 개선을 보였습니다. 이는 기존 비만·당뇨 사업 뒤를 이을 제품군 확대 가능성을 뒷받침합니다. Lilly 발표 경쟁사의 개발 진전은 분명 주시해야 하지만, 서로 다른 시험 수치를 직접 비교해 Lilly의 경쟁력이 약화됐다고 단정할 근거도 없습니다.
