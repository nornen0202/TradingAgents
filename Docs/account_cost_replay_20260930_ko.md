# 제공 수수료·환전우대 반영 후속 검증

작성: 2026-09-30. 비용 입력 근거: 사용자가 2026-09-29 제공한 KIS 수수료 화면 3장과 환전우대 60%. 현재 비용으로 과거 시장을 다시 계산하는 연구이며, 당시 실제 계좌 수익이나 신고세액을 재현한 결과는 아니다. 거래 전송 기능은 포함하지 않는다.

## 비용 입력과 충돌 처리

| 항목 | 적용 값 | 근거와 범위 |
|---|---:|---|
| 국내 일반주식 KRX 수수료 | 매수·매도 각각 0.147% | 제공 화면의 영업점 온라인 요율 |
| 국내 일반주식 NXT 수수료 | 각각 0.146% | 제공 화면; KRX와 호가·유동성이 같다는 가정은 하지 않음 |
| 국내 주식형 ETF 수수료 | 각각 0.147% | 제공 화면; 일반주식 매도세를 ETF에 더하지 않음 |

[KIS 수수료·세금](https://www.truefriend.com/main/customer/guide/_static/TF04ae010000.jsp), [SEC Section 31](https://www.sec.gov/rules-regulations/fee-rate-advisories/2026-2), [KIS 기본 환전우대](https://m.truefriend.com/main/customer/guide/_static/TF04ae040100.shtm), [KIS USD 스프레드 설명](https://mini.truefriend.com/stock/event/index1.html).

스크린샷은 일반 안내 화면이므로 사용자가 제공한 계산 입력으로 채택하되, 개인별 우대나 API 주문매체까지 독립 확인한 것으로 표시하지 않는다. 화면 하단의 미국 최소 체결금액 $0.01 설명을 최소 수수료 $0.01로 오독하지 않는다. 수수료 최소금액·반올림은 미확인 상태이며 비례요율을 적용한다. 다른 나라의 세금은 미국·국내 모델에 섞지 않는다.

가격·환율이 그대로인 왕복 거래의 비용 손실은 국내 KRX 일반주식 약 0.4933%, 국내 주식형 ETF 0.2936%, USD를 유지한 미국 거래 0.5008%, 원화→USD→원화까지 포함한 미국 거래 1.2936%다. 마지막 경우 가격이 약 1.3106% 올라야 비용만 상쇄한다. 정수 잔돈·슬리피지·양도소득세·최소수수료는 이 단순 예시에 포함하지 않았다.

## 추가한 재현 도구

`tradingagents/execution/account_cost_replay.py`와 `tools/replay_account_costs.py`는 다음을 계산한다.

- 실제 수량 계산에는 비조정 Open/Close를 사용하고 정수로만 거래한다. Adj Close는 완료 월 신호에만 사용한다. 분할이 있는 입력은 다른 원장이 필요하므로 거부한다.
- 원화·달러 가격 변화를 구분하고, 매매 시점에는 전일까지 알려진 FX만 사용한다. 미래 환율로 빈 값을 채우지 않으며 5일 초과 오래된 환율을 거부한다.
- 처음 전액을 운용통화로 바꾸고 마지막 가상 청산 후 원화로 바꾸는 모형이다. 미국 전략의 현금 20%도 USD이며 거래할 때마다 환전비를 반복 부과하지 않는다.
- FIFO 취득원가와 원화 실현손익으로 연도별 양도세 충당액을 계산한다. 같은 연도의 손익만 상계하고 연도 간 손실은 이월하지 않는다. 충당액은 재매수 가능 현금에서 제외한다.
- 해외주식 공제 250만원 전액 잔여/이미 소진의 두 경우를 비교한다. 각 시장·계좌에 공제를 중복 부여하는 통합 실적은 만들지 않는다. [국세청 공제·손익통산](https://i.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8800&mi=12274)
- 분배금은 배당락일 직전 보유분에 대해 인식한다. 지급일 자료가 없어 재투자하지 않고 미수 배당금으로 평가한다. 마지막 NAV에는 아직 인출 가능하다고 확정하지 않은 배당채권도 포함한다.
- 22% 해외 양도세, 미국 분배금 15%·국내 주식형 ETF 분배금 15.4% 원천징수는 일반 거주자 계좌의 연구 가정이다. 개인 과세 특례·종합과세·실제 세무 환산환율·신고 납부일을 재현하지 않는다.

계좌 검토 JSON에 저장된 시장별 NAV 규모로 각 기간을 현금에서 독립 시작한다. 기존 개별 보유분의 전환 매매나 과거 제안의 실적은 아니다. 국내·미국 조회 자산에는 현금 중복 가능성이 있어 합산하지 않는다. 월간 추세/변동성 및 분기 80/20 규칙은 앞선 연구와 동일하다. 4개 기간 × 4개 전략 × 3개 슬리피지(0/5/15bp) × 2개 추가 지연(0/1일), 시장별 공제 가정을 조합한다. 현재 수수료를 과거에 적용한 비용 민감도이며 역사적 수수료는 아니다. 기존 연구와 달리 마지막 가상 매도 비용과 세금도 포함하므로 수익률 차이를 모두 수수료 효과로 해석할 수 없다.

```powershell
$env:PYTHONPATH='.'
python tools/replay_account_costs.py --price-dir <비공개_가격폴더> --account-review <비공개_account-review.json> --output <비공개_출력폴더>
```

필요 가격 파일은 `SPY_raw.csv`, `069500.KS_raw.csv`, `KRW_X_raw.csv`다. 원본 가격, 입력 파일 SHA-256, 실험별 거래·곡선·비용 및 중단 사유를 비공개 산출물에 남긴다. API 키나 계좌번호를 인자로 요구하지 않는다. 결과는 로컬 분석용이며 주문 수량 추천으로 연결하지 않는다.

## 가격 자료의 새 제한

비조정 시세를 새로 수집하자 국내 ETF 2024-10-30은 분배금 120원만 있고 가격이 누락돼 있었다. 해당 날짜가 필요한 2024–2026 연속 실험 24개는 중단했고 가격이나 배당을 임의로 삭제·보간하지 않았다. 2026-07-31의 약 +24.17% 변동도 여전히 공식 시세 대사가 필요하다. 미국 192개·국내 72개, 총 264개를 계산했으며 국내 결과는 가격 품질 제한을 함께 표시한다. 과거 조정가격 캐시로 얻은 국내 장기 성과도 이 문제를 해결하기 전까지 채택 근거로 사용하지 않는다.

낮은 회전율과 불필요한 환전 축소는 비용 측면의 기본 방향이다. 80/20은 비교 기준으로 유지하되, 모든 기간의 원화 낙폭을 줄이거나 개인별 최적 배분임을 보장하지 않는다. 정확한 기존 계좌 전환 세액은 취득 내역·세무 환율·다른 계좌의 같은 연도 실현손익이 있어야 계산할 수 있다.
