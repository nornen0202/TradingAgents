# 국내·미국 모의매매 실행 점검과 재발 방지

## 확인한 원인

2026-10-21 11:00 KST 전후 운영 원장과 예약 작업을 확인했다. 예약 작업 성공은 체결 성공을 뜻하지 않는다. KIS 시험 주문·체결·취소 검증은 완료됐지만 전략 계정은 국내·미국 모두 `NO_FILLS`였다. 내부 가상계좌도 체결이 없었다. 기존 실계좌 보유자산을 복제한 내부 평가 변동은 전략 수익이 아니다.

- 국내 내부 가상매매의 누적 거절 612건에는 주문 배정이 없는 종목 분석상 EXIT 의견이 포함됐다. 계좌 전략은 종가 확인을 기다려 HOLD이고 `proposed_orders`는 비어 있었다. 이 상태를 수량 없는 주문으로 만드는 것은 소비자 오류다. 종가 확인을 생략하거나 임의 수량을 만들지 않는다.
- Windows Time은 실행 중이지만 동기화 원본이 Local CMOS Clock이고 외부 시간 동기화가 확인되지 않았다. time.windows.com에 대한 3회 측정은 약 +0.94초였다. 시스템 시계가 느리면 수신 호가가 미래로 보인다. 자동 재동기화 명령은 운영 계정의 관리자 권한 부족으로 거부됐다.
- 미국 최신 원본은 KIS 실시간 시세·호가·체결강도가 있었지만 거래정지 상태가 unknown이었다. 이 때문에 `DELAYED_ANALYSIS_ONLY`가 적용됐다. `mtyp` 또는 일반 `stat`를 정지 여부로 추정할 수 없다.
- 매도 예산에 수수료를 더해 나누면 정확히 1주인 위험 축소 제안이 0주가 된다. 해외 원화 환산 가격을 정수로 잘라 수량을 재산정하는 문제도 있었다.
- 내부 평가 원장은 시세가 불완전한 관측도 NAV 값으로 저장하지만 관측별 완결성은 저장하지 않았다. 이 값을 검증된 성과로 취급하면 안 된다.

## 변경

1. 내부 가상매매도 명시적인 동일 종목·방향 주문 제안과 분석 신호가 함께 있을 때만 주문 후보를 만든다. 중복 제안, 잘못된 명시 수량, 예산 방향 불일치는 차단한다. 배정 없는 분석 의견은 거절 주문으로 누적하지 않는다. 과거 원장은 삭제하지 않는다.
2. 매도 예산을 줄일 총 보유가치로 해석하고 비용은 체결 대금에서 차감한다. 매수에는 기존 비용 포함 한도를 적용한다. 승인된 정수 매도수량과 소수 원화 환산 가격을 보존한다. 매도 가능 수량, 일일 한도, 매수 현금 하한 등 정책은 그대로 적용한다.
   계좌 전략의 `TRIM_NOW`·`STOP_LOSS_NOW`도 각각 기존 브로커의 `REDUCE_NOW`·`EXIT_NOW` 검증 경로에 연결한다. 분석과 동일 방향의 명시 제안이 없으면 주문을 만들지 않는다.
3. Nasdaq 공식 거래정지 RSS를 미국 공급자에 연결한다. 프로세스 내 종목 간 조회를 공유하고 성공·실패 모두 최소 60초 간격을 지킨다. 게시 시각이 누락·미래·120초 이상 과거이면 사용하지 않는다. 항목 수, 종목, 정지 및 재개 시각, 중복 충돌을 검증한다. 예정된 미래 재개나 호가 재개만으로 거래 재개를 인정하지 않는다.
4. 해당 RSS는 **현재 정지일의 항목**을 제공하며 여러 날 지속된 정지를 모두 나열하지 않는다. 따라서 목록 부재만으로 clear를 만들지 않는다. 같은 뉴욕 날짜의 양수 거래량이 있는 완료 분봉이 게시 시각 이전에 확인되고 신선할 때만 이전 날짜부터 계속된 정지를 배제한다. 이후 당일 정지는 RSS로 확인한다. 증권사가 명시적으로 정지를 알리면 정상 피드보다 우선한다. LULD 밴드·Reg SHO·뉴스 사유 전체를 제공한다고 주장하지 않는다.
5. 원본 만료, 날짜 불명, 자료 미충족, 정상적인 주문 미배정을 구분해 `source_diagnostics`와 안전한 조회 화면에 제공한다. 자료가 불충분한 상태를 일반적인 신호 대기로 감추지 않는다. 주문 없이 평가만 하는 내부 작업은 `VALUATION_ONLY`다.
6. 미래 호가와 오래된 호가를 구분해 원래 사건 시각·실제 수신 시각·시간차를 남긴다. 미래 호가는 여전히 제외하며 `CLOCK_SYNC_REVIEW_REQUIRED`를 표시한다. 허용 오차를 늘리거나 시각을 현재로 덮어쓰지 않는다.
7. `observation_quality`에 새 관측의 평가 완결성을 영속화한다. 과거 관측을 검증 완료로 소급하지 않는다. `valuation_performance`는 평가 불완전 시 손익·수익률을 null로 제공하고, 완전한 평가도 초기 복제 보유자산을 포함한 성과라고 표시한다. 전략만의 수익률을 임의로 계산하지 않는다.

## Windows 시간 복구

관리자 PowerShell에서 `tools/repair_windows_time.ps1`을 실행한다. Windows Time의 자동 시작, 외부 NTP 원본 및 300초 조회 주기를 구성하고 실제 재동기화를 요청한다. 성공 여부는 명령 실행뿐 아니라 외부 원본 동기화 상태, 측정 오차, 다음 정상 호가 수신으로 확인한다. 도메인 정책 관리 PC에서는 관리자 정책을 우선한다. 권한 부족은 코드 변경으로 우회하지 않는다.

일회성 설정 화면 동기화만으로 지속 운용 복구를 선언하지 않는다. 기존 1분 소비자의 시각 차단 진단과 다음 장중 원본의 완결성을 함께 확인한다. 미국 장외에 완료한 피드 조회를 미국 장중 전략 체결 검증으로 보고하지 않는다.

## 검증 기준

- 외부 호출 없는 정상·빈·누락·잘못된·미래·오래된 시각 테스트, 재개 예정·재정지·불완전 RSS·다일 정지의 목록 부재 검사.
- 신호와 주문 제안 결합, 정수 수량·비용·환산 정밀도, 다음 관측에서만 체결, 재시작 중복 방지, 위험 축소와 신규 매수 분리.
- 평가 불완전에서 손익 공개 차단, 이후 정상 시세에서 회복, 과거 관측 미소급.
- 운영 반영 후 기존 예약 작업의 소스 revision과 새 진단 필드를 확인한다. 실제 거래 신호가 없거나 정상 제약에 막힌 경우 강제로 시험 전략 매매를 만들지 않는다.

운영 원장을 읽기 전용으로 복사한 11:19 KST 검증에서 새 코드가 원래 호가와 수신 시각의 -0.24~-0.61초 차이를 기록하고 `CLOCK_SYNC_REVIEW_REQUIRED`를 표시했다. 주문 미배정 원본에서는 새 거절 주문을 만들지 않았다. 이 검증은 원본 운영 원장을 변경하거나 증권사 주문을 전송하지 않았다. Nasdaq 실제 응답의 게시 시각·항목 수·정지/재개 시각 파싱도 확인했다. 장외 피드 조회는 미국 정규장 실행 검증을 대체하지 않는다.

## 2026-10-21 미국 정규장 후속 복구

사용자가 관리자 시간 복구를 실행한 뒤 23:27:38 KST의 Windows Time 상태는 leap indicator 0, stratum 4, Cloudflare 동기화였다. 23:36의 독립 NTP 표본 중앙값은 약 +11ms였고 이후 AAPL 실제 날짜 포함 호가도 미래 시각 차단 없이 통과했다. 스크립트는 작은 측정 오차만으로 성공하지 않고 동기화 상태도 검사한다. 선택적인 `-StepClock`은 두 서버 일치와 5초 이내 오차를 확인하며 원래 보정 임계값은 실패 시에도 복원한다. 미래 호가 허용이나 저장 시각 수정은 하지 않는다.

거래정지 상태는 주문 범위를 명시한다. 최신 공식 RSS와 날짜 있는 거래봉으로 LUDP/T5 등 보고된 거래 중단 및 T1/T2 등 뉴스 정지를 검사한다. **실시간 LULD 상·하한 밴드 제공은 아니다.** 해당 밴드는 공급자에서 제공하지 않음을 유지한다. Reg SHO Rule 201은 공매도 가격 제한이고 현재 경로는 매수 또는 실제 매도 가능 보유량 내 매도만 지원하므로 `not_applicable_long_only`로 표시하며 공매도 제한 상태 자체를 clear라고 선언하지 않는다. 모든 종류의 활성 정지, 불명·누락·만료·미래 피드는 계속 차단한다.

BRK-B는 KIS가 요구하는 `BRK/B`로 조회해야 한다. 실제 읽기 조회에서 `BRK-B`, `BRK.B`는 빈 가격, `BRK/B`는 `DNYSBRK/B`와 정상 가격을 반환했다. 명시적인 동일 종목 별칭을 분리하고 거래정지 비교에도 적용했다. 주식 종류 접미사를 잘라 다른 종목을 조회하지 않는다. 수정 후 BRK-B 실제 KIS 호가·체결강도·거래정지 증거의 누락은 없었다.

분석 만료 원인은 120초 소비 유효기간보다 긴 생산 지연과 5분 호출 간격이었다. 실행 전용 갱신은 원래 연구 근거를 보존하고 새로운 시세·거래정지·계좌 데이터를 다시 수집하며, 뉴스 재수집과 종목별 차트 렌더링을 발행 필수 경로에서 제외한다. 모의매매 활성화 시 기존 생산 잠금을 공유하는 정기 장중 overlay에도 같은 경로를 적용해 예약 시각마다 지연이 재발하지 않게 한다. 전체 연구와 별도 웹 보고 경로는 유지한다. 생산자 설치 기본 주기를 1분으로 분리하고 60초부터 실제 관측 갱신을 시작한다. 실패 재시도는 300초·3회 제한을 유지한다. 시세 유효기간은 120초 그대로다.

별도 아카이브의 실제 30종목 검증은 `20261021T234147_lightweight-verification`에서 54.79초에 완료됐다. 발행 시 29종목 시세 나이는 57.65초이며 실행 데이터 검증을 통과했다. 나머지 BRK-B는 위의 별칭 수정 후 독립 실제 조회로 복구를 확인했다. 원래 전략 주문 제안은 비어 있었고 이를 임의의 전략 주문으로 바꾸지 않았다. 미리보기 결과를 운영 체결로 간주하지 않는다.

별칭 수정 후 두 번째 실제 30종목 검증 `20261021T235120_lightweight-all-symbols`는 36.31초에 완료됐다. 30종목 모두 실행 데이터 검증을 통과했고 발행 당시 원래 시세 나이는 55.44초였다. 23:28 이후 23:52까지 미국 내부 평가 27회도 연속 완결성 검사를 통과했으며 23:53 NTP 중앙값은 약 +12ms였다.
