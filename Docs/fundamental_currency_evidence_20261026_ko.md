# 재무 요약의 거래통화와 재무보고통화

2026-10-26. 자료 수집 성공, 내용의 검증, 원래 투자 판단과 실제 주문 승인은 각각 다른 단계다. 정상 전략의 BUY/SELL이나 비용 후 수익을 이 변경의 검사 수로 대신하지 않는다.

## 확인한 전달 누락

`y_finance.get_fundamentals`는 이미 받은 `info`에서 수치와 회사 정보를 골라 반환했지만 `currency`와 `financialCurrency`는 전달하지 않았다. 새 반환은 두 공급자 필드를 각각 거래통화와 재무보고통화로 표시한다. USD 거래·TWD 재무처럼 서로 다를 수 있으므로 한쪽을 다른 쪽으로 채우지 않는다. 한국 종목의 프로필 KRW도 재무보고통화의 대체 증거가 아니다.

기존 공급자 응답을 다시 조회하지 않는다. 원래 수치·문자열·순서·종목 fallback과 빈 응답 처리는 유지한다. 세 재무제표 getter에 별도 `info` 요청을 추가하지 않으며 금액 재스케일, 주식 수나 ADR 환산도 수행하지 않는다.

## 확인 범위와 미확인 값

누락·빈 값은 `UNVERIFIED_MISSING`, 잘못된 형식은 `UNVERIFIED_MALFORMED`, 세 영문자이지만 대문자 코드 형식이 아닌 값은 `UNVERIFIED_NONSTANDARD_VENDOR_TOKEN`으로 표시한다. 객체·제어문자 등 잘못된 원문은 그대로 출력하지 않는다. `GBp`를 `GBP`로 바꿔 펜스를 파운드로 해석하지 않는다.

세 ASCII 대문자는 공급자가 보고한 token의 형식만 확인한 것이다. ISO 등록 여부, 천·백만 단위, 주당 수치의 주식 기준, ADR 비율, 재무제표 기간 길이, 공시·접수 시각을 증명하지 않는다. 이 한계를 반환 헤더에 함께 표시한다. 확인하지 못한 단위·공시시점을 통화 코드 하나로 충족 처리해서는 안 된다.

기존 `Current vendor snapshot; not verified point-in-time` 고지를 유지한다. 과거 Yahoo 개요·재무제표 거절, 분석 cutoff 주입, router의 미래·잘못된 날짜 거절과 기간 필터를 바꾸지 않는다. 현재 수집 시각을 과거 공시 시점으로 대체하거나 최신 메타데이터를 이전 연구에 소급하지 않는다. 미래일 거절 검사는 기존 router 경계의 증거이며 direct leaf에 새 미래일 검사를 추가한 것으로 설명하지 않는다.

## 실제 원본에서 확인할 수 없는 부분

10월26일 정상 국내 full 연구의 첫 000660 분석은 재무 통화·단위·주식 기준 등이 미확인이라고 기록했다. 저장된 graph/final/report는 가공 서술을 보존하지만 당시 Tool 본문은 응답 해시·상태만 남아 있다. 따라서 당시 공급자가 해당 메타데이터를 제공했는지, 이 전달 누락이 최종 WAIT를 발생시켰는지는 확정할 수 없다. 기간 열 2026-06-30이 전달된 사실과 실제 공시일·기간 길이 검증은 별개다.

원래 WAIT는 가격 구조와 보상·위험에 관한 독립 사유도 명시한다. 필수 correlated 요청 COMPLETE는 모든 경제적 불확실성 해소나 BUY 승인이 아니다. 공통 프롬프트의 ADR 문구도 원문은 ‘필요한 경우’로 한정하므로 국내 종목에 ADR이 잘못 적용됐다고 단정하지 않는다. 원래 분석·판단·시각·원장을 수정하지 않는다.

## 검증과 다음 실제 조건

외부 API 없는 새 35개 fixture는 혼합 통화·각 누락·잘못된 값·GBp·미등록 가능 token·기존 수치·fallback·빈 응답·과거 조회·router의 미래/잘못된/누락 날짜·추가 provider 요청 0을 확인한다. 관련 기존 11개와 독립 원래 getter 비교 10조건도 통과했다. 범위가 겹치므로 합산하지 않는다. 최신 main 통합·정확한 head CI·배포는 별도 영수증으로 판정한다.

다음 원래 정상 연구에서 실제 받은 값과 새 표시, 필수 자료·원래 승인·완료 원본 채택을 확인해야 한다. 현재 살아 있는 immutable 소스의 연구에 이 코드를 소급 적용하거나 재시작하지 않는다. 이 수정으로 실제 체결 개선이나 수익성을 주장하지 않는다. 계좌·owner·승인·한도·잠금·재시도 예산과 실계좌/자동 실투자 전환 비활성을 보존한다.
