# 미국 정상 Yahoo 연구 입력의 고정 검증

## 실제 관측과 범위

2026-10-23 배포된 PR452의 공개 가격 가용성 검사에서 DELL은 Yahoo 가격과
SMA200 계산을 통과했지만, 최초 가격 입력과 지표 재조회 입력의 정확한 값은
달랐다. 별도 캐시의 기본 CSV 파서와 round-trip 파서를 오프라인으로 비교한
결과 최대 차이는 약 5.684e-14였고 SMA200 차이는 0이었다. 경제적으로 유의한
신호 변화나 실제 주문 오류가 관측됐다고 주장하지 않는다.

근거는 G:/TradingAgentsData/migration-audits/us-prior-failure-price-availability-20261023/result.json과
그 아래 DELL/private-cache의 원문이다. 이 검사는 정상 연구·승인·체결 검증이
아니다. 나머지 6개 실패 종목의 불량 OHLCV·자료 범위 차단도 유지한다.

## 수정 계약

미국 KIS 연구 복구가 활성인 기존 경로에서 정상 Yahoo도 최초 검증 프레임을
연구 범위에 고정한다. 가격과 후속 지표는 같은 입력을 사용하고, 복사된 병렬
컨텍스트에서도 최초 선택 승자의 입력을 반환한다. 반환 자료를 수정해도 고정
원문은 바뀌지 않는다. 더 좁은 조회는 투영하고 최초 범위보다 넓은 조회는
거절한다. 새 연구 범위에서는 다시 정상 캐시·조회 정책을 적용한다.

CSV 재읽기는 round-trip 수치 파서를 사용한다. 고정 입력을 재사용할 때에는
캐시 원문이나 수정 시각을 다시 쓰지 않아 이전 자료의 캐시 수명을 연장하지
않는다. 기존 복구 미활성 가격 경로, KIS 전체 시계열·상장 근거 검증, 5년 기본
계산 창, 시점 필터 및 재시도 예산은 유지한다.

Yahoo의 수집 시각·거래소·과거 빈티지 근거를 새로 만들어 넣지 않는다. 프레임
고정과 출처 검증은 다르며 기존 근거 수집기는 이를 검증된 KIS 시계열로
승격하지 않는다. 원래 승인·계좌 소유권·공유 잠금·원장·한도는 변경하지 않는다.

## 오프라인 검증 및 운영 미충족

새 회귀는 외부 HTTP를 금지하고 정상 전체 시계열에서 캐시 무효화와 변경된
후속 응답, 새 연구의 재조회, 독립 캐시 읽기의 정확한 수치, 반환값 변조,
좁은/넓은 범위, 병렬 선택, 미활성 경로 및 미검증 출처 상태를 확인한다.
보완 전 5개 중 4개 실패로 입력 교체·수치 재읽기·프레임 부재·병렬 불일치를
재현했다. 날짜 dtype 해상도 차이는 동일 날짜 값과 구분한다.

배포 후 정상 예약 연구가 이 코드를 채택했는지, 동일 입력이 지표까지 유지되는지,
장중 연속 신선도와 정상 전략 체결·실제 비용이 충족되는지는 별도 증거가 필요하다.
실계좌 주문과 자동 실투자 전환은 비활성으로 유지하며 현재 실투자 판정은
NOT_READY다.
