# 회사 뉴스 누락 및 OTC 참고 시세 복구

대상: `20261116T175030_local-scheduler-us-full`의 30종목. 원본 보고서의
분석 완료 수와 연구 입력 검증·주문 가능 여부는 서로 다른 상태다.

## 원인과 수정

- 기존 미국 뉴스 경로는 Alpha Vantage → Yahoo 두 공급자에 의존했다.
  실제 재현에서 전자는 한도/구독 오류, 후자는 뉴스 API 오류와 검색 결과
  공백을 반환했다. 실제 사용 가능한 Alpaca 뉴스와 Massive 뉴스 경로를
  추가하고 미국 정기 분석의 우선 경로에 연결했다. 한국 뉴스 경로에서는
  이 두 미국 공급자를 제외한다. BRK-B는 Alpaca에서 결과가 없었지만
  Massive의 정확한 클래스 B 식별자 `BRK.B`에서 기사를 확보했다.
- 공급자 요청의 날짜만 신뢰하지 않는다. Alpaca 기사는 발행·수정 시각,
  타임존, 요청 기간, 실행 기준일, 현재 시각, 정확한 종목 태그를 로컬에서
  검사한다. 미래·누락·잘못된 시각과 기준일 이후 수정된 기사는 제외한다.
- Massive는 기사 버전의 수정 시각을 제공하지 않으므로 현재 날짜를 포함한
  수집에만 사용한다. 과거 날짜나 과거의 정확한 시각을 기준으로 한 분석은
  거절한다. 발행 시각과 조회 시각을 별도로 보존한다. 두 공급자 모두
  제한된 기사 표본임을 표시하고 빈 결과를 '뉴스 없음 검증 완료'로 취급하지 않는다.
- TCEHY는 KIS의 NAS/NYS/AMS 조회에서 가격이 없었다. 기존 기본 공급자
  체인은 Yahoo로 대체 조회할 수 있었으나 KIS만 지정한 진단은 이 경로를
  확인하지 못했다. 이제 대체 시세에도 앞선 공급자 실패의 안전한 사유 코드를
  남긴다. Yahoo의 날짜 없는 행·미래 행·충돌하는 중복 시각·잘못된 OHLCV를
  집계 전에 제외하고, 하루 거래량과 이전 일봉 평균의 시점을 분리했다.
- TCEHY의 실제 Yahoo OTC 분봉은 지연 시세였다. 원래 거래 시각을 보존하며
  `DELAYED_ANALYSIS_ONLY`, 호가 미제공, 거래정지 확인 불가 상태를 유지한다.
  KIS 상장 종목이나 홍콩 원주 가격으로 바꿔치기하지 않는다.

공급자 계약: [Alpaca News API](https://docs.alpaca.markets/us/v1.1/reference/news-3),
[Massive Stock News](https://massive.com/docs/rest/stocks/news).

## 실제 재수집과 검증

2026-11-17 02:11:02–02:13:31 KST에 원래 30종목 모두에서 다음 8개 도구를
새로 호출했다: 일봉, 기술지표, 회사 뉴스, 기업 개요, 재무상태표, 현금흐름,
손익계산서, 공시. 일봉의 끝은 당시 마지막 완료 거래일인 11월 13일이다.
회사 뉴스는 11월 9–16일 UTC 창에서 각 호출 시점까지 검증했다.

추가 확인에서 TCEHY의 연간 현금흐름 표는 조회됐지만 분기 자료의 대용으로
간주하지 않았다. SEC의 `UNMAPPED_INSTRUMENT`는 공시가 없다는 확인이 아니다.
ETF의 재무제표 항목을 임의로 면제하거나 분기·연간 주기를 섞어 통과시키지 않았다.

이 검증은 **새 입력의 가용성과 원본 연구 증빙 검증**이다. 새 LLM 투자 판단을
생성한 것이 아니며, 27개 입력 통과 결과를 과거 27개 투자 판단의 승인으로
소급 적용하지 않는다. 기존 연구 매니페스트 SHA-256은
`58a0d40c4ac12ef1cda0cbcfcdfec13237c4275326816357f51f5b8b946bd687`로 유지됐다.

수집 원문·영수증·원본 검증·별도 계좌 및 30종목 시세 재확인 결과는 운영
저장소의 `verification/news-recovery-20261117/`에 보관한다. 계좌 식별자,
인증 정보와 비공개 계좌 원문은 공개 저장소에 포함하지 않는다.

## 유지한 보호 기준과 회귀 검증

`PRESERVE_STRICTER_RULES`, 기존 손절·비중·한도, 계좌·미체결 재확인,
시세 신선도와 정규장 호가·거래량·거래정지 확인 기준은 변경하지 않았다.
미검증 연구의 신규 매수 차단과 위험 축소 매도의 구분도 그대로다.
실제 주문과 보고서의 투자 판단 변경은 수행하지 않았다.

외부 API 없이 실행되는 회귀 테스트는 정상/빈/잘못된 응답, 미래·누락·잘못된
날짜, 기사 수정 시점, 클래스별 종목 태그, 인증 오류, 페이지 반복·상한,
KR 경로 제외, 공급자 복구 영수증, TCEHY 지연 시세의 비승격을 검증한다.
