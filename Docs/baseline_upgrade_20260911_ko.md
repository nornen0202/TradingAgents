# 기준 프로젝트 비교와 투자 판단 개선 — 2026-09-11

더 강한 모델, 원문 근거 전달, 시점 통제, 재현 가능한 계산으로 투자 판단의 신뢰도를 높였다. 실제 초과수익을 입증한 변경은 아니다. 모델 확신도나 테스트 통과를 수익 확률로 해석하지 않는다.

## 확인 범위

- [사용자 지정 zdoc](https://www.zdoc.app/ko/TauricResearch/TradingAgents)는 2026-08-31 번역본이다.
- 공식 [v0.4.0 릴리스](https://github.com/TauricResearch/TradingAgents/releases/tag/v0.4.0)와 `origin/main`의 `be952b8e`까지 소스를 비교했다. 이후 소스 병합 이름 v0.4.2를 공식 배포 버전과 혼동하지 않았다.
- 시작점은 사용자 fork의 `1529cdfa`. 기존 작업 폴더의 미커밋 수정은 별도 작업 공간으로 분리해 보존했다.
- 모델 설정, 자료 공급 경로, 그래프/CLI, 구조화 판단, 장중 조건, 계좌 배분, 성과 계산, 보고서와 테스트를 확인했다.
- 로컬 `results/GOOGL/2026-04-05/reports/final_trade_decision.md`, `results/SPY/2026-04-05/reports/final_trade_decision.md`는 과거 서술형 출력 사례로 검토했다. 최신 시세나 검증된 수익률의 증거로 쓰지 않았다. 조건 설명에 비해 초보자가 재현할 손익비·손실액 계산 안내가 부족했다.

## 모델 정책

[Sol 공식 문서](https://developers.openai.com/api/docs/models/gpt-5.6-sol)와 [이전 안내](https://developers.openai.com/api/docs/guides/upgrading-to-gpt-5p6-sol)를 확인했다. 실제 Codex `model/list`에 Sol이 있으며 xhigh 호출도 성공했다.

| 역할 | 기본 모델 | 추론 수준 |

| 심층 판단·트레이더 | gpt-5.6-sol | xhigh |
| 자료 분석·강세/약세·위험 토론 | gpt-5.6-sol | high |
| 판단 검증 | gpt-5.6-sol | xhigh |
| 투자자 설명 작성 | gpt-5.6-sol | high |
| 번역·출력 | gpt-5.6-sol | medium |
| YouTube 종합 | gpt-5.6-sol | high |

초기 분석에서 누락한 근거를 최종 판단이 복구하기 어렵기 때문에 자료 분석도 Sol로 올렸다. 낮은 모델 등급으로 비용을 줄이는 대신 역할별 추론 수준과 결정론적 계산으로 효율을 확보한다. 비용·지연은 늘 수 있다. 토큰 여유가 있다는 요청을 반영했으며 운영 요청 제한 시간은 600초다.

배포 전 검사와 실행 시 자동 모델 강등은 기본 비활성화했다. Sol이 없으면 명시적으로 실패한다. 구형 모델 수동 선택이나 fallback 환경변수는 호환용으로 남아 있다. 이를 켜면 품질 정책을 의도적으로 벗어난다. 일반 예제의 gpt-5.4 고정도 제거했다. 기본 provider는 Codex이고 API 공급자는 명시적으로 선택할 수 있다.

## 초보자를 위한 투자 안내

종목 보고서 앞의 **투자 전 한눈에 확인**은 신규 진입과 기존 보유 위험 대응을 구분한다. 같은 Markdown을 정적 종목 페이지도 읽는다.

- 서로 맞는 구조화 진입·손절·첫 목표 가격이 있을 때만 계산한다. 복수 진입안·통화 혼합·잘못된 값은 검토 필요로 표시한다.
- 비용 반영 손익비, 1주당 계획 손실, 손익분기 승률을 계산한다. 손익분기 승률은 산술 문턱이며 예측 확률이 아니다.
- 기본 비용은 편도 10bp 가정이다. 실제 수수료·호가 차이·체결 오차로 바꾸며 세금·환전은 별도다.
- 기준일, 실행 전 확인, 손절 체결의 불확실성, ETF/현금 대안, 주요 용어를 설명한다.
- 수량은 현금·기존 보유를 포함한 종목 한도·새 주문의 손실 예산 중 가장 엄격한 값으로 제한한다. 주문을 제출하지 않는다.

같은 통화 단위의 산술 예제이며 실제 종목 추천이 아니다:

```powershell
python -m tradingagents.investor --capital 10000 --cash 500 --entry 100 --stop 95 --existing-position-value 800 --risk-fraction 0.005 --max-position-fraction 0.10 --cost-bps 10
```

예제 결과는 1주다. 전체 포트폴리오 상관관계·환율·세금·급락 체결까지 고려한 최적 비중은 아니다. 실제 배분은 기존 계좌 제약과 장중 승인 절차를 함께 확인한다. 파일은 `0_summary/investor_playbook.md`와 검증용 JSON에 저장한다. 과거 보고서를 현재 보고서처럼 덮어쓰지 않는다.

## 성과 평가의 수정

기존 워크포워드에는 당일 종가 진입, 미완료 수익 사용, 종목 간 회전율 공유, 미래 결과 즉시 학습, 서로 겹치는 종목/기간을 한 계좌처럼 복리 계산하는 문제가 있었다.

현재는 **신호 연구**로 명시한다. 다음 거래일 시가 진입, 전체 보유 기간 뒤 종가 평가, 비용 차감, 미완료 구간 제외 사유를 기록한다. SELL을 자동 공매도로 바꾸지 않는다. 종목별 노출 변화를 따로 관리하고, 겹치는 기간이나 국가가 섞이면 계좌 최대낙폭을 만들지 않는다. 한국 기본 비교는 한국 ETF, 미국은 SPY이며 관측 구간이 같아야 초과수익을 계산한다. 기존 계좌 NAV/TWR/동일 현금흐름 ETF 벤치마크는 유지한다.

엄격 평가에서는 Yahoo 현재 기업정보/재무를 과거 정보로 사용하지 않는다. 그래도 모델 사전학습의 미래 지식, 재무 정정본, 생존 종목 선택, 가격 조정은 완전히 제거되지 않는다. 체결 기록 없는 추천 추적은 실현 수익률이 아니다. 수익 개선 판단에는 이후 기간 모의운용과 실제 비용·체결 기록이 필요하다.

## 사용·운영

```powershell
python -m cli.main analyze --checkpoint
python main.py --ticker AAPL --date 2026-09-10
python main.py --ticker AAPL --date 2025-03-03 --historical
```

실시간 보고서는 최신 vendor snapshot을 표시해 활용한다. 과거 엄격 평가는 `point_in_time_strict=True`를 사용한다. 두 경로를 동일한 시점 정확도로 취급하지 않는다. 영속 학습과 체크포인트는 사용자 홈 `.tradingagents`에 저장한다. `memory_dir=None`이면 저장을 끈다. 체크포인트는 선택 기능이다. 결과 관측 후 `reflect_and_remember(..., outcome_known_at="YYYY-MM-DD")`로 학습한다. 인지일을 모르는 수동 기록은 현재 날짜로 보수적으로 기록한다.

## 검증과 한계

변경 전 918 tests, 78 subtests가 통과했다. 변경 후 전체 회귀는 **973 tests, 78 subtests 통과, 1 skipped**다. 추가 검증은 실제 SQLite 복구, 미래 학습 차단, 공시 JSON, 뉴스 경계, DST, 최신 종가, 경로, 유한 수치, 비용·수량, 평가 순서, 자동 강등 금지를 포함한다. 고위험 정적 검사, 의존성 잠금 일치, wheel 빌드도 통과했다. 기존 모바일 화면과 새 투자 안내 표를 각각 360/390/430px에서 확인했으며 가로 넘침이 없었다. 원격 CI 결과는 PR 검증 기록에 남긴다.

실제 Yahoo 시세와 Sol xhigh 응답을 확인했고, AAPL 2026-09-10을 대상으로 4개 분석가·투자 토론·위험 토론·최종 판단·보고서 저장까지 실제 실행했다. 실행 비용을 분리해 확인하기 위해 이 검증 보고서는 영어로 저장했다. 복수 진입 시나리오의 수치를 섞지 않고 손익비 계산을 보류하는 동작도 확인했다. 전용 소셜 자료는 부족해 대체 경로를 사용했으며, FRED 키가 없는 경로의 정상 저하와 vintage 요청은 모의 응답으로 검증했다. 미확인 공급자의 실연동, 모든 시장의 성능 무하락, 투자 수익 극대화를 입증했다고 주장하지 않는다.
