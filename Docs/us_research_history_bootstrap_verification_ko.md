# 미국 정상 분석의 가격 보고 전 전체 계산 이력 검증

실제 시장 분석 노드는 최초에 370일 가격 보고를 요청한 뒤 지표를 계산한다.
최근 가격만 정상이면 Yahoo를 먼저 고정할 수 있었지만, 이후 5년 지표 입력에서
오래된 결함이 발견되면 이미 선택한 원천을 KIS로 바꿀 수 없었다. 원천 고정
검사는 혼합을 막는 올바른 동작이며, 그 검사 전에 검증 범위를 완성해야 한다.

외부 API 없는 실제 함수 호출 순서로 두 실패를 보존했다.

- 기존 코드는 오래된 Close 누락을 지표 계산까지 전달해
  `InsufficientIndicatorHistoryError`로 실패했다.
- 전체 OHLCV 검증만 추가하면 잘못된 시계열은 발견하지만, 최근 Yahoo가 이미
  선택돼 `Daily history source changed within the same research`로 실패했다.

원본 재현 로그는 G:/TradingAgentsData/migration-audits의
`us-history-bootstrap-before-fix-20261023.txt` 및
`us-history-bootstrap-whole-validation-before-bootstrap-20261023.txt`다.
이는 오프라인 재현이며 특정 운영 종목의 실제 실패 원인으로 소급 표시하지 않는다.

수정은 기존 복구가 활성화된 미국 종목의 첫 가격 보고에서도 전체 5년 계산
입력을 먼저 검증하도록 한다. 한국 종목의 기존 선검증 경로와 같은 순서다.
최근 보고의 출력 범위는 그대로 유지한다. Yahoo 전체 입력이 정상이라면 Yahoo를
유지하고, 오래된 결함·누락이 있으면 원천을 고정하기 전에 KIS 전체 시계열로
복구한다. KIS 자료를 Yahoo 캐시에 저장하지 않는다.

미국 복구 경로는 최근 마지막 행뿐 아니라 분석일 이내의 모든 유효 날짜에서
Open/High/Low/Close/Volume의 존재·유한성·가격 양수·수량 비음수와 고저 범위를
검증한다. 미래 날짜는 이 검증과 계산에 기여하기 전에 제거한다. 날짜를 확인할
수 없는 중간 행이 빠져 거래일 구멍이 생기면 기존 전체 거래일 검사로 거절하거나
검증된 전체 KIS 자료를 사용한다. 잘못된 행을 보정하거나 공급자별 행을 섞지 않는다.

기존 단일 원천 고정, KIS 전체 프레임 고정, 지표 최소 관측, 상장일·시점 계약,
연구/재시도/주문 한도, 원래 승인·소유권·잠금·원장은 유지한다. 복구를 활성화하지
않은 기존 가격 전용 조회의 동작은 바꾸지 않는다. 자료 선검증이 정상 연구 완료나
BUY 승인·주문·체결을 대신하지 않는다.

검사는 실제 최초 시장 도구의 인자를 사용해 가격 함수→지표 함수를 호출한다.
최근 Yahoo 정상/과거 불량+KIS 전체 정상, 전체 Yahoo 정상, 복구 미활성,
빈/누락 필드, 미래·검증 불가 날짜, 과거 비정상 가격·수량을 Mock으로 검증한다.
배포·정상 예약 연구의 채택·체결·비용 성과는 각각 별도 운영 증거가 필요하다.
