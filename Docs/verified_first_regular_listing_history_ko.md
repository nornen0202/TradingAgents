# 검증된 최초 정규 상장일과 기존 5년 계산창

GEV의 KIS 일봉은 최초 정규 상장 이전까지 5년 전체 거래일을 요구해 실패했다.
첫 관측일을 상장일로 추정하거나 모든 종목을 370일로 줄이는 대신, 독립적으로
검토한 동일 증권의 최초 정규 상장 사건과 새 KIS 식별 응답이 모두 일치할 때만
상장 전 거래일 요구를 제외한다. 원래 요청 시작일은 그대로 기록한다.

현재 검토된 사건은 GEV 보통주의 2024-04-02 NYSE 정규 거래 개시다.
자료 수집 완료의 최댓값은 **2026-10-23 01:20:11.116019 UTC**이며,
이 검토가 그 전에 가용했다고 표시하지 않는다.

[SEC 2024-03-08 공시](https://www.sec.gov/Archives/edgar/data/1996810/000119312524063739/d808872d8k.htm)는
정규 거래 개시 예정과 앞선 when-issued 시장을 구분한다. 예정 문구만으로 실제
개시를 확정하지 않고 위 실제 발행사 공시와 대조했다. 일반 API의 상장일 필드만으로
이전 상장·재상장·거래소 이전·when-issued를 최초 정규 상장 사건으로 등록하지 않는다.

PR447 배포 후 실제 KIS 조회에서 표준 종목번호와 기관 ISIN이 모두
US36828A1016, 거래소 NYSE, 통화 USD, 상장일 20240402로 확인됐다.
그 가운데 CUSIP 36828A101은 위 발행사 보통주 자료와 일치한다. 실제 원문과
수집 시각은 G:/TradingAgentsData/migration-audits/kis-gev-search-info-original-20261023.json에
보존했다(SHA256 0cefe7a3d3f2cbf6583fd21c030d14311bfc0f2427706683c77bcef4983bd871).
이 단회 응답을 영구 재사용하지 않는다. 새 일봉 수집에서는 현재 KIS 메타데이터를
다시 확인하고, 기관 ISIN·표준 번호·발행사·거래소·통화·상장일·상장/폐지/이전
상태를 모두 검증한다. 필드가 없거나 충돌하면 범위를 완화하지 않는다.

가격 종료일과 분석 기준일은 다를 수 있다. 원래 분석 설정의 `analysis_as_of`를
US 시장의 뉴욕 날짜로 해석하고, 그 날짜 종료와 실제 현재 시각 중 이른 시각을
식별 자료의 상한으로 삼는다. 설정이 없으면 요청 가격 종료일이 기준일이다.
따라서 장전 분석은 이전 완료 일봉을 요청하면서도 명시된 현재 분석일에 가용한
식별 자료를 사용할 수 있다. UTC 자정으로 뉴욕 저녁을 다음 분석일로 오인하지 않는다.
과거 분석일에 현재 응답을 소급해 넣지 않으며 원래 연구·승인 시각은 변경하지 않는다.

보존하는 계약:

- 원래 `min(요청 시작, 종료일−5년)`과 MODP=1 조정 방식은 유지한다. 검증된
  상장일이 더 늦을 때만 필요한 정규 거래일 시작이 달라진다. 충분히 오래 상장된
  종목과 검토되지 않은 종목에는 메타데이터 조회나 범위 변경을 추가하지 않는다.
- 상장 이후의 모든 완료 거래일이 있어야 한다. 첫날·중간·마지막 누락, 비거래일,
  잘못된 날짜와 OHLCV, 충돌 중복을 계속 거절한다. 확인된 정규 거래 시작 이전
  날짜의 제외는 별도로 기록하며, 잘못된 정규 일봉을 삭제하거나 보정하지 않는다.
- 기존 120초 수집 예산에 메타데이터 시간도 포함한다. 같은 연구의 가격·지표는
  같은 전체 시계열과 계약을 고정한다. 다른 연구의 캐시가 식별 자료 300초를 넘기면
  다시 바인딩한다. 값 계산과 지표 최소 관측 수는 그대로여서 신규 상장 직후
  200일 SMA 등이 부족하면 계속 실패한다.
- 영수증은 원래 5년 요청, 실제 필요한 정규 시작일, 검토 사건/원문 해시,
  식별 응답의 가용시각·필드·해시를 구분한다. 장식용 frame 속성만 믿지 않고
  검토 사건과 다시 검증한다. 가격·세금·프롬프트는 이 영수증에 넣지 않는다.
- 이력은 현재 조회한 조정 시계열이며 과거 실제 보관 빈티지가 검증됐다는 뜻이
  아니다. 기존 빈티지 미검증 표시와 원래 승인·계좌·주문·한도·예산을 보존한다.

검증은 외부 API 없는 Mock으로 수행한다. 정상/빈/미래/누락/잘못된 날짜,
식별·종류·이전/폐지·when-issued 충돌, 뉴욕/UTC 경계, 원래 분석일,
전체 상장 후 일봉과 누락 거절, 캐시 만료, 단일 원천 고정, 지표 최소 이력을 다룬다.
단위 검사·배포·실제 자료 수집·정상 연구 채택·원래 승인·체결·비용 성과는
각각 별도로 판정하며, 실패한 과거 연구를 수정하거나 예산을 초기화하지 않는다.
