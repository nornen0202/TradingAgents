# 투자 브리핑 배포 알림과 거래일 실행

## 달라지는 동작

기존 `투자 분석 완료` 알림은 전체 원천 분석의 성공과 전략 반영을 뜻한다. 새 `투자 브리핑 배포 완료` 알림은 특정 보고서 발행본의 실제 공개를 뜻한다. 두 사건을 구분하고 기존 완료 판정을 거짓으로 완화하지 않는다.

- 지연 데이터 보고서: 원래 분석·가격 시각을 보존한 조건부 투자 계획. 게시 시각이 가격 갱신을 뜻하지 않는다.
- 부분 분석 보고서: 확보한 종목만 다루고 누락·실패 종목과 범위를 표시한다.
- 갱신 브리핑: 동일한 원천 분석을 바탕으로 설명이나 통찰을 보완한 별도 발행본. 변경된 보고서 해시마다 알린다.
- 확정되지 않은 미래 자료나 훼손된 원본은 여전히 배제하며, 보고서 발행은 주문을 승인하지 않는다.

## 전달 경로

`publish → ACK → handoff → 공개 배포 확인 → work_report outbox → 기존 Telegram workflow → SENT 영수증`

배포기는 공개된 최신 KR/US 보고서를 내용 주소 기반 원본과 대조한다. 새 알림은 생산자의 전체 성공·시세 TTL·자료 나이에 의존하지 않는다. 최초 적용 때 현재 공개된 최신 보고서 각 한 건만 회수하며 과거 보관함 전체를 재전송하지 않는다.

전송 시 배포 잠금 안에서 공개 스냅샷, 불변 보고서 JSON/HTML, PC·모바일 전략 페이지의 실제 바이트를 재확인한다. 알림은 해당 해시의 불변 보고서 링크와 PC·모바일 전략 링크를 제공한다. 최신 보고서가 바뀌어도 이전 알림의 보고서 링크는 바뀌지 않는다. 기존 사이트의 최근 30일 보관 정책은 유지한다. 원본 손상·미배포·전파 지연은 PENDING으로 남고 성공 알림을 보내지 않는다. 전송 원장이 보고서별 중복을 막고, 결과에는 보고서 해시와 Telegram 메시지 ID를 기록한다.

## 거래일 예약

현재 호출 시각은 한국시간 KR 월~금 10:40/13:40/14:40, US 월~토 01:10/03:10/23:10이다. 정기 실행은 `prepare --scheduled-market --report-policy investor`로 시작한다. 시장 현지 날짜의 주말 및 확인된 휴장은 이벤트 생성 전에 `SKIP_NON_TRADING_DAY`로 종료한다. 미국은 뉴욕 시간대와 DST를 적용하므로 한국 토요일 새벽은 금요일 거래일이고, 월요일 새벽·토요일 밤 호출은 건너뛴다. 단일 기존 예약을 유지하여 작성자 중복을 만들지 않는다.

달력 조회 장애는 휴장으로 단정하지 않는다. `CALENDAR_UNVERIFIED_REPORT_ALLOWED`를 남기고 날짜가 표시된 투자 참고 보고서를 허용한다. 즉시 주문 검증은 기존 엄격한 경로를 유지한다. 수동 보고서 발행 및 이미 배포된 보고서의 알림 재시도는 주말·휴장일에도 가능하다.

## 검증

외부 API 없이 실제 packet → draft → publish 경로로 만든 지연·부분 보고서, 동일 분석의 수정 발행본, 중복 전송, 손상/누락/미래/잘못된 시각, 배포 중 상태, HTML 바이트 불일치 및 배포 잠금을 검사한다. 거래일 테스트는 한국·미국 주말, 공휴일, DST 전환, 달력 장애, 잘못된 날짜의 달력 응답, 주문 경로 우회를 검사한다. 실제 운영 반영과 Telegram 영수증은 배포 후 별도로 확인한다.
