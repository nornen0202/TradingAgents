# 국내·미국 KIS 모의 주문 연결과 정규장 검증

2026-10-18 구현. 실계좌 자동 주문은 비활성으로 유지한다. 별도 투자 Workbench는 만들지 않고 기존 로컬 검토 화면과 운영 작업에 연결한다.

## 투자자가 확인하는 변화

- 기존 해외 연결은 인증·잔고·주문내역 조회까지였다. 이제 전용 해외 모의 키를 사용하는 미국 지정가 매수·매도·취소, 주문내역 대조 경로를 추가했다. 자동 검증은 아래의 소액 모의 매수·취소만 수행한다.
- `http://127.0.0.1:8766`에서 조회 연결과 주문 검증을 따로 표시한다. 국내·미국 각각 주문 접수, 누적체결 관측, 취소 완료 세 단계와 확인 시각을 읽을 수 있다. 차트 오류나 비어 있는 종목 목록이 운영 상태를 숨기지 않는다.
- 미국 호가 응답의 `output1` 날짜·종목과 `output2` 매수·매도 가격을 함께 읽도록 수정했다. 실제 읽기 응답으로 구조를 확인했으며, 수량을 가격으로 잘못 쓰지 않는다. 이 수정은 지속 로컬 모의매매에도 적용된다.
- 로컬 가상체결과 증권사 모의 서버 체결은 서로 다른 원장과 상태다. 조회 성공·주문 접수·체결·취소·정산은 각각 다른 사실이며, 정산 증거 없는 누적체결을 정산된 실현손익으로 기록하지 않는다.

## 자동 검증 범위

| 항목 | 국내 | 미국 |
|---|---|---|
| 전용 모의 계정 저장 | 사용자 DPAPI 국내 묶음 | 사용자 DPAPI 해외 묶음 |
| 검증 종목 | 069500 | AAPL / NASD |
| 주문 | 1주 지정가, 최대 2건 | 1주 지정가, 최대 2건 |
| 금액 상한 | 건당 10만원, 총 20만원 | 건당 500달러, 총 1,000달러 |
| 취소 | 주문별 최대 1회 | 주문별 최대 1회 |
| 최초 대상 정규장 | 2026-10-19 09:00 KST | 2026-10-19 22:30 KST |

개장 직후 2분은 기다린다. 실제 실행 시 공식 세션과 휴장을 다시 확인하고 120초 이내 날짜 있는 가격·전용 모의계좌 주문 가능 금액을 검증한다. 미국 정규장 시간은 서머타임에 따라 바뀌므로 고정 시각만으로 주문하지 않는다.

첫 주문은 현재 가격보다 낮은 제한가격으로 접수 후 취소를 검증한다. 둘째 주문은 체결 관측을 위한 지정가이며 5분 동안 체결되지 않으면 취소한다. 국내 날짜 없는 호가는 새 검증 주문의 근거에서 제외하고 날짜 있는 완료 분봉 가격으로 제한가격을 정한다. 미국은 날짜 있는 호가를 사용한다. 체결 가능성을 보장하지 않으며, 취소 전에 체결되거나 응답이 모호하면 추가 주문으로 성공을 만들지 않고 `ATTENTION`에 남긴다.

고정 캠페인 ID와 SQLite 원장에 네트워크 호출 전 의도·시도를 기록한다. 재시작해도 같은 주문을 다시 보내지 않는다. UNKNOWN 주문은 자동 재전송하지 않는다. 주문 기록이 없는 성공 JSON, 원장과 다른 주문 조건, 미래·잘못된 확인 시각은 완료 증거로 인정하지 않는다. 인증·요청 간 대기 중 시간이 역행하면 발송 전 중단하며, 발송 후 응답 시각이 역행하면 UNKNOWN으로 유지한다.

## 실제 운용

- `LocalAutomation-validate-kis`: 매분 유한한 검증을 한 단계씩 진행한다. 완료된 시장은 추가 주문하지 않는다. 전용 `enabled.json`의 명시적 활성 상태와 모의 전용 모드를 확인한다.
- `LocalAutomation-paper`: 기존 매분 로컬 모의매매 작업이다. 유효한 최신 분석과 시세·계좌·위험 조건이 있을 때만 가상 주문을 처리한다. 거래가 없으면 이유를 보존한다.
- `LocalAutomation-review`: 같은 PC의 읽기 전용 화면이다. 주문을 보내는 웹 API는 없다.
- Codex의 이 채팅 후속 일정은 두 작업의 실제 기록을 확인하고 새 완료·장애·복구·운영 결과가 있을 때 보고한다. 다른 채팅이나 메신저로 새 메시지를 보내지 않는다.

로컬 실행에는 PC가 켜져 있고 해당 Windows 사용자가 로그인되어 있어야 한다. 채팅의 예약 결과 보고에는 Codex 앱도 실행 중이어야 한다. 과거 성공 시각을 현재 시각으로 바꿔 정상 운영으로 표시하지 않는다.

설치 명령은 `tools/install_kis_session_validation.ps1 -EnableDemoValidation`이다. 기존 분석·발행 작업의 일정은 바꾸지 않는다. 실행 코드는 `fork/main`의 불변 스냅샷을 사용한다. 모의 인증 토큰도 DPAPI 암호문으로만 저장하고 키·계정·시장 및 만료 시각이 일치할 때 재사용한다. 실전 키는 모의 인증의 대체값이 아니다.

비상 중지는 `C:/Projects/TradingAgents/.runtime/local-automation/kis-validation/HALT` 파일이다. 새 주문을 중단하면서 기존 모의 주문의 조회·취소 정리는 허용한다. 캠페인·원장 삭제로 재실행 한도를 우회하지 않는다. 별도 로컬 모의매매 중지는 기존 `paper/HALT`를 사용한다.

## 검증 증거와 한계

10월 18일은 휴장일이다. 국내·해외 모의 인증·잔고·주문내역 조회는 확인했고, 추가로 해외 세 거래소 잔고와 USD 주문 가능 금액의 완전한 조회를 확인했다. 이날 실제 서버 주문·체결·취소 성공을 주장하지 않는다. 이 항목은 다음 정규장의 브로커 응답으로만 완료된다.

오프라인 테스트는 KR/US 정상·빈·미래·누락·잘못된 날짜, 분리된 호가 응답, USD/KRW 분리, 현금·보유·일일 한도, 시계 역행, 응답 유실, 재시작, 중복 방지, 부분체결·취소 경쟁, 허위 완료 영수증, 화면의 과거 시점 제외와 모바일 표시를 검증한다. 실제 장중 운영 성과는 첫 정규장 이후 별도 확인하며 단기 모의 결과로 전략 수익성을 입증하지 않는다.
