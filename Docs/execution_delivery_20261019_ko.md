# 장중 실행 신호 전달과 미국 모의 서버 시각 보정

2026-10-19 국내 완료 원본 8개에서 실행 후보 행은 9개였다. 그중 8개는 원본 완료 시점에 이미 시세 시각 + 120초를 넘었고, 나머지 1개도 약 5초만 남았다. 14:40 시세로 만든 실행 판단이 14:42:21에 전달된 것이 한 사례다. 다만 해당 행은 모두 지속 전략 관심목록 밖의 매도/축소 판단이고 명시적 주문 제안은 0개였다. 전달 지연을 고쳐도 이 기록이 승인된 전략 주문으로 바뀌지는 않는다.

기존 경로는 시세 수집·판단 후 종목별 뉴스 조회를 수행하고 보고서 차이 계산에서도 뉴스를 다시 조회했다. 이제 날짜를 검증한 뉴스를 먼저 수집하고 같은 내용을 두 단계에서 재사용한다. 뉴스의 명시적 기준 시각 이후, 3일 이전, 날짜 누락·오류·시간대 누락 자료는 제외한다. 시세와 판단의 원래 시각은 보존하며 120초 실행 유효기간과 10분 보고서 신선도는 변경하지 않는다.

완료 manifest의 원자적 저장 뒤 기존 내부 가상매매 및 KIS 모의 전략 소비자를 즉시 호출한다. 로컬 예약 생산자는 자신의 state 경로를 명시적으로 전달하고, 보고 직전 갱신은 같은 생산자 state를 사용한다. 각각의 기존 enabled 설정과 모드, 실계좌 비활성 값이 일치해야 호출한다. 기존 소비자가 실행 중이면 잠금에 의해 양보하고 정규 주기를 유지한다. 원장·캠페인·신호 ID·신호 시각을 새로 만들거나 초기화하지 않는다. 유한 연결 검증 작업은 이 호출에 포함하지 않는다. 상태는 `execution-handoff/latest.json`에 개인정보 없이 남는다.

미국 첫 정규장에서는 `HHDFS76200100` 호가 응답의 `dymd/dhms`를 뉴욕시간으로 해석해 미래 시세로 차단했다. 2026-10-19 13:33:58 UTC에 읽은 응답은 `20261019/223359`였으며 한국시간 시계임을 확인했다. 해당 호가는 Asia/Seoul, 분봉의 `xymd/xhms`는 거래소 현지 시간으로 각각 해석한다. 현재 시각에 맞는 시간대를 골라 쓰지 않는다. 자정·서머타임 변경, 1초 미래, 121초 지연, 전일 자료를 검증한다. 원본 시각이 미래인 응답은 이 수정 후에도 거절한다.

확인은 `http://127.0.0.1:8766/`의 KIS 연결 검증·지속 전략·내부 모의매매 카드에서 한다. 연결 검증의 체결과 전략 체결은 별도 원장이다. 주문 접수만으로 체결·취소 완료를 선언하지 않으며 미확인 비용·정산을 순손익으로 표현하지 않는다. 국내 장중 실측 개선은 다음 정규장 원본 완료 시각, 원래 시세 시각, 즉시 소비 영수증을 대조해야 한다.

## 미국 원주문 대조에서 추가 확인한 형식 차이

22:50:55 KST 첫 모의 주문 접수 후, 접수 응답의 10자리 주문번호와 조회 응답의 앞자리 0을 생략한 5자리 번호가 문자열 비교에서 불일치했다. 숫자값·계좌·날짜·종목·거래소·가격·수량은 일치했고 미체결 1주였다. 대조 시에만 1~10자리 ASCII 숫자의 앞자리 0을 제거해 비교한다. 저장된 원주문 번호·의도·요청을 변경하거나 다시 제출하지 않는다. 서로 다른 번호, 중복 조회 행, 다른 원주문 조건, 미래 시각, 0 번호, 부호·공백·소수점은 일치로 처리하지 않는다. 취소 자식 주문과 원주문의 연결에도 같은 비교를 적용하되 취소 완료 상태와 수량 검증은 유지한다. 대조 장애는 기존 코드의 정상 후속 조회가 성공할 때만 해소한다.
