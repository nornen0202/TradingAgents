# 과거 추천과 현재 체결을 구분하는 차트 안내

2026-10-26. 실제 보관 화면에서 계획 가격 이름을 기본 숨김으로 바꾼 뒤에도 과거 추천 글자가 캔들을 가리는 현상이 남았다. SIGNAL은 추천 이력이며 현재 BUY 승인이나 증권사 체결이라는 뜻이 아니다. 이번 수정은 표시와 읽기 동작을 다루며 연구·승인·주문·체결·원장·수익 계산은 바꾸지 않는다.

## 사용하는 방법

1. 기본 차트는 과거 추천 화살표를 유지하고 추천 글자만 숨긴다. 실제·데모·내부 모의 체결을 포함한 모든 다른 표식의 글자·색·도형·좌표는 그대로다.
2. 차트의 **과거 추천 글자 표시**를 켜면 원래 전체 문구가 보인다. 일봉·분봉 체크박스는 독립이며 Tab·Space로 조작할 수 있다. 해당 차트에 추천이 없으면 비활성이다.
3. **가격 이름 표시**는 별도 조작이다. 추천 토글이 가격선이나 다른 차트 상태를 바꾸지 않는다.
4. **과거 추천 원문 확인**을 열면 제공된 전체 문구·중복·순서와 원장의 정밀 시각을 확인한다. 작은 화면에서는 표에 초점을 두고 가로로 스크롤하며 긴 표는 자체 영역에서 세로로 움직인다.

## 원문·시각·출처의 경계

도표 표식과 SIGNAL 원장 기록은 각각 원래 순서로 표시한다. 두 표를 추정해서 연결하지 않고 초 단위 도표 좌표로 원래 마이크로초 시각을 복원하지 않는다. 제공된 사건·가용·수집·확정 ISO 문자열의 정밀도와 offset을 유지한다. 개별 원장이나 시각이 없으면 미제공이라고 표시한다.

현재 선택한 전체 보고서 run을 개별 추천 출처로 채우지 않는다. 개별 출처·run은 한정된 안전한 필드만 표시하고 미확인은 그대로 남긴다. 계좌·owner·주문번호·파일 경로·전체 payload를 새로 보여주지 않는다. 원문은 텍스트로 삽입해 HTML로 실행하지 않으며 snapshot·cutoff 필터 결과도 변경하지 않는다.

다른 종목·시각을 선택한 뒤 옛 체크박스가 새 차트에 적용되지 않도록 현재 요청 세대·연결된 컨트롤·현재 차트를 함께 대조한다.

## 검증과 남은 실제 확인

외부 API 없는 Node 5사례는 SIGNAL 글자만 숨김, 모든 체결·다른 표식 불변, 원문·중복·정밀 시각·누락·개인정보, 두 차트의 독립 토글과 오래된 핸들 무효화를 확인했다. 기존 가격선 Node 4사례와 이를 실행한 pytest wrapper 2개는 중복 합산하지 않는다.

합성 360·390·430·1440px 화면에서 양쪽 차트의 실제 Space 키 토글, 원문 접기·펼치기, 표 내부 키보드 스크롤, 체결 표시, 가격 토글 독립과 옛 핸들 호출 차단이 통과했다. 390·1440px 차트와 원문 표를 이미지로 확인했다. 처음 fixture가 빈 lifecycle에 항상 events 배열이 있다고 가정한 실패는 원본 보존했고 수정한 fixture의 성공과 구분했다. 독립 읽기 리뷰에서 추가 P1/P2는 없었으며 독립 실행으로 집계하지 않는다.

최종 정확 head CI·병합·배포와 실제 운영 보관 화면 KR/US·390/1440 검사는 별도 기록이다. 합성 표식은 테스트에만 주입하고 운영 원장에는 넣지 않는다. 화면 통과를 정상 전략 BUY/SELL·비용·수익 검증으로 세지 않는다.
