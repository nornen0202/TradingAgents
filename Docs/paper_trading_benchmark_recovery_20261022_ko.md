# 국내·미국 모의매매 실행 복구와 벤치마킹

기준일: 2026-10-22. 목표는 정상 연구에 의한 국내·미국 매수·매도 증권사 모의 체결, 전략 원장에 귀속된 성과와 실투자 적용 여부를 판단할 근거다. 기존 검증 캠페인, 내부 시뮬레이터, 증권사 전략 성과는 서로 합산하지 않는다. 실계좌 주문은 비활성이며 이 문서는 실투자 전환 승인이 아니다.

## 원래 분석과 실행의 단절

운영 근거 `zero-strategy-fill-causal-audit-20261022.json`에서 양국 30종목씩 연구·트레이더·최종 판단을 직접 대조했다. 세 단계 모두 WAIT이고 모델 오류 대체 응답은 없었다. 국내 전체 연구는 10월22일 07:58, 미국은 10월21일 21:44에 끝났다. 각 30종목 모두 자료 검토 필요였다. 원래 수집 실패 횟수는 국내 7~13회, 미국 6~18회다.

장중 경량 갱신은 기존 연구를 유지하고 선택 재분석을 끈다. 일반 예약 작업도 full 또는 overlay_only만 호출한다. 따라서 정상 재분석의 생산·채택 경로가 있어야 자료 복구가 새 승인으로 이어진다. 시세 저장 시각이나 원래 연구를 수정해서 승인을 만들지 않는다. 선행 주문과 매도 가능 보유분이 없는 상태에서는 정상 전략 매도도 불가능하다.

## 첫 구현: 요청 단위 자료 심사

새 연구는 각 Tool 요청에 별도 ID를 부여하고 공급자별 시도와 최종 결과를 연결한다. 같은 요청이 대체 공급자에서 복구된 경우만 복구로 집계한다. 다른 요청의 성공으로 이전 실패를 덮지 않는다. 원시 실패 횟수는 진단에 남긴다.

기본 필수 근거는 가격, 지표, 회사 뉴스, 기업 개요, 재무상태표, 현금흐름표, 손익계산서, 공시다. 각 필수 Tool은 실제 호출되고 요청이 모두 완료·사용 가능해야 한다. 미매핑·불완전 공시 조회, 빈 응답, 오류, 누락·미래·역행·날짜 없는 요청 기록은 통과시키지 않는다. 기존 Tool의 기준일·공개 시점 검증은 그대로 적용한다. 소셜·거시·내부자 등 보조 자료의 미확보는 불확실성으로 기록하며 필수 자료를 대신하지 않는다.

요청 기록이 없는 과거 분석은 기존 실패 횟수 차단을 유지한다. 과거 원본의 검토 필요를 소급 해제하지 않는다. 모의 주문 계획도 요약의 COMPLETE 문구만 신뢰하지 않고 원래 analysis.json의 요청 기록·종목·분석 완료 시각을 다시 대조한다. 새로운 자료 통과는 원래 WAIT를 매수로 변경하지 않는다. 다른 위험·검토 조건과 계좌 한도는 유지한다.

PR426은 `f3ec639586b8a0a38f41e6674a4b29e8fb354b96`으로 병합했다. 최종 Windows 검사는 4,196개·131개 하위 검사(1개 제외), 화면 회귀 4종, Ruff와 CodeQL이 통과했다. 16:14 KST의 정규 전략 작업에서 이 버전을 확인했다. 양국 시장은 닫혔으며 정상 전략 주문·체결은 여전히 0건이다. 이 배포 확인을 새 연구 또는 체결 성공으로 해석하지 않는다.

## 두 번째 구현: 독립적인 정상 재분석과 완료 원본 채택

`research-kis`는 기존 시세 생산자·미결 주문 대사·전략 주문 작업과 다른 잠금을 사용한다. 기존 모의 전략의 명시적인 활성화가 있어야 작동한다. 연구 실행에는 증권사 주문 객체를 만들지 않는다. 원래 `create_llm_client` 기반의 전체 종목 분석 경로를 그대로 호출해 새 판단을 생성한다.

거래소 현지 시각 기준 국내 10:10·13:10, 미국 10:00·13:00의 각 30분 입장 구간만 사용한다. 한 구간당 최대 2종목, 하루 2구간이며 이미 검토한 종목을 다시 선택하지 않는다. 실패·시작 후 중단도 구간을 사용한 것으로 보존한다. 기존 허용 종목·원래 건당 금액 안에서 1주 가격을 충족하고, 날짜가 검증된 120초 이내 정규장 관측이 있는 기존 연구 종목을 선택한다. 이는 연구 우선순위이며 주문은 최신 시세·승인·계좌·위험 한도를 다시 검사한다. 기존 주문 횟수나 신규 진입 횟수는 변경하지 않는다.

재분석 요청은 원본 명세·분석·계약의 해시, 전체 연구 종목 목록과 선택 종목을 고정한다. 선택 종목만 새로운 자료로 다시 분석한다. 나머지 원본과 계약은 바이트와 시각을 보존한다. 전체 커버리지, 원본 불변성, 새 분석의 실제 시작·완료 시각과 계약 일치를 검증한 완료 결과에만 별도의 연구 갱신 기록을 붙인다. 새 결과의 WAIT는 그대로 남긴다.

장시간 연구보다 늦게 시작한 시세 갱신이 `latest-run.json`을 차지해도 다음 갱신은 같은 전체 연구에 연결된 새 완료 분석을 발견한다. 실패·부분 완료·미래 시각·다른 시장·원본 변경·결과 손상이 있는 갱신은 채택하지 않는다. 더 새 전체 연구가 완료되면 이전 전체 연구의 갱신은 이를 덮지 못한다. 시세 갱신은 채택한 연구를 바탕으로 새 관측을 수집하고 기존 120초 기준을 다시 적용한다.

실제 기존 국내 원본에서 연구 계보 탐색은 0.026초, 갱신 후보 탐색은 0.553초였다. 이는 읽기 전용 탐색 측정이며 장중 600초 공동 소비 검증이나 실제 체결 증거가 아니다. 새 작업의 설치·배포 및 운영 재분석·장중 검증 결과는 운영 기록으로 별도 확인해야 한다.

## 남은 실행·평가 완료 조건

1. 자료 복구 후 제한된 정상 재분석을 독립적으로 실행하고 완료 원본만 장중 소비자에 전달한다. 오래 걸리는 연구가 분 단위 시세 생산이나 미결 주문 대사를 막지 않아야 한다.
2. 국내 검증 캠페인의 원래 승인·원장·일일 한도 안에서 실제 BUY·SELL을 확인한다. 10월22일의 0주 취소는 체결이 아니며 이미 사용한 일일 횟수에 남긴다.
3. 국내·미국 각각 정상 전략 BUY·SELL의 증권사 보고를 원장으로 확인한다. 정당한 진입·청산이 없으면 체결 수를 채우기 위해 신호를 만들지 않는다.
4. 전략별 버전, 신호·제출·접수·체결 시각과 가격, 수량, 실제/추정 비용의 구분, 손익·보유기간·최대낙폭과 비교 지표를 보존한다. 비용을 모르면 순손익을 0원 비용으로 계산하지 않는다.
5. 실투자 적용 판단에는 반복 가능한 표본, 비용·슬리피지 민감도, 다른 기간 검증, 장애·부분 체결·재시작 대사, 사용자의 별도 실계좌 활성화 결정이 필요하다. 한 번의 왕복 체결이나 단위 검사 통과를 수익성 또는 실투자 준비 완료로 표시하지 않는다.

현재 이 문서의 구현·설계는 정상 전략 실제 체결이나 성과 완료 증거가 아니다. 운영 근거는 `.runtime/local-automation/live-verification/`의 원본 관측과 증권사 원장에 별도로 남긴다.
