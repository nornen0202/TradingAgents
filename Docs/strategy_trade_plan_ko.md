# PC·모바일 매매 전략표

PC `/strategy.html`과 모바일 `/mobile/strategy.html`의 KR·US 화면은 같은 `mobile/strategy.json`을 사용한다. 기존 검색·정렬·종목 유형·분석 방향 필터를 유지하며, 종목마다 검토 수량, 가격 범위 또는 발동 기준, 비용을 반영한 예상 금액, 발동 조건과 현재 상태를 보여준다. 긴 조건은 표 안에서 펼쳐 전문을 읽을 수 있다.

## 계산 원칙

- 현재 실행과 동일한 실행의 계좌 자료만 사용한다. 실행 ID, 시장, 완료 상태, 스냅샷 시각·보유 목록을 대사하고 원본 계좌 식별정보는 게시하지 않는다.
- 현재 행동과 조건부 행동을 구별한다. `HOLD`와 포트폴리오 상대 축소 의견만으로 즉시 매도 계획을 만들지 않는다. 명시된 조건부 음수 배정액과 위험 가격이 있으면 조건부 축소 시나리오로 표시한다.
- 매수는 가격 범위 상단·수수료를 포함해 정수 수량으로 내림한다. 모든 종목이 하나의 잔여 예산을 공유하고 매도 예정 대금은 선사용하지 않는다. 명시된 0원은 다른 현금 값으로 바꾸지 않는다.
- 매도는 보유 수량과 매도 가능 수량을 넘지 않는다. 명시된 전량·20%·35% 매도 계획만 비율로 계산하고 자유로운 문장을 수량으로 해석하지 않는다. 소수점 보유분을 1주로 올리지 않는다.
- 가격은 구조화된 진입·위험 수준에서 가져온다. 돌파·이탈 기준값은 체결 범위가 아니며, 현재 시세에 임의 비율을 더해 범위를 만들지 않는다. 호가 단위 및 조건 충족 후 실제 체결 가격은 다시 확인해야 한다.
- 유한한 숫자 `low/high`가 원문에 단 하나로 명시된 통화 가격 구간을 벗어나면 구조화 응답의 기존 제한된 재작성 절차를 사용한다. 예를 들어 원문 `75,200~75,700원`의 구조화 범위가 `75~75,200`이면 오류다. 일치하거나 포함되는 하위 구간은 허용하고, 단일 임계값(`low == high`), 부분값·문자열 값, 단위 불명, 여러 구간이나 별도 범위 밖 확인 가격이 있는 문장은 의미를 추정하지 않는다. 비율·지표 구간이나 1달러 미만 가격에 일률적인 크기 기준을 적용하지 않는다.
- 과거 분석에 이 불일치가 있으면 원문·숫자·분석 해시를 고치지 않는다. 새 overlay는 복사된 실행 계약도 검증해 `structured_price_range_conflict` 사유와 함께 현재·조건부 행동을 모두 중지한다. Work는 원래 투자 논리를 보존하고 해당 종목만 `NEEDS_LIVE_RECHECK`로 낮추며 명시 구간과 구조화 숫자 재확인을 요구한다. 계좌 행동표의 기존 배정은 `reference_plan`으로 보존하고 현재 배정을 비활성화한다. PC·모바일 매매 계획도 이 종목의 행동·수량 산정을 보류하므로 최신 계좌·시세가 있어도 잘못된 가격이 실행 계획으로 되살아나지 않는다. 보고서는 이 차단 사유와 재확인을 누락하거나 실행 가능으로 승격할 수 없다.
- 비용은 사용자가 제공한 국내 0.147%, 미국 0.25%와 비용 프로필의 매도세를 이용한다. 미국 거래금액은 USD로 표시하고 실제 매매 비용과 환전 비용을 구별한다. 원화 매수 예산에는 기준 스프레드 1%·우대 60%에 따른 편도 0.40%를 보수적으로 별도 유보한다. 이 유보액은 실제 환전비가 청구됐다는 의미가 아니며, 이미 보유한 USD를 사용하는 경우와 구별한다.
- 미국 원화 배정액을 환산할 명시적 USD/KRW 자료가 없으면 추정하지 않는다. 향후 기존 KIS 해외 잔고 조회의 USD 기준환율을 저장하며, 과거 자료를 새 환율로 덮어쓰지 않는다. 이 기준환율은 실제 환전 호가와 다르다.

수량 0주(추가 배정 없음·1주 미만 등)와 산출 보류(가격·환율·잔고 등 근거 부족)는 구별한다. 계좌·시세·계획의 만료 상태는 브라우저에서도 갱신하며, 분석이 최신이어도 계획이나 계좌의 확인이 끝나지 않았다면 현재 주문 없음으로 표시한다. 수량은 입력 계좌 기준의 수동 검토안이며 주문 전송·주문 승인을 제공하지 않는다.

## 구성과 검증

- `tradingagents/scheduled/trade_plan_sources.py`: 같은 실행에 연결된 계좌·환율 입력만 제한적으로 읽는다.
- `tradingagents/scheduled/trade_plan.py`: 수량·가격·비용과 산정 근거를 만든다.
- `tradingagents/scheduled/mobile_site.py`: PC 표와 모바일 카드형 표를 같은 데이터에서 렌더링한다.

일반 공개 리서치의 비계좌 정보 정책은 유지한다. 매매 검토 수량은 사용자가 요청한 전략 전용 데이터에만 추가한다. 자동 테스트는 현금 중복 사용, 매도 가능 수량 0, 누락 환율, 만료 계획, 개인정보 제거를 검증하며, 360·390·430·1440px 브라우저 검사는 표·검색·시장 전환·접근성·조건 전문 표시를 확인한다.
