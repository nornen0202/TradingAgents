## 완료 직전인 새 원본의 전달

PR420은 전체 4,036개 검사·131개 하위 검사·화면 회귀 4개·Ruff·CodeQL을 통과했다. 실제 보고서 전처리는 37.98초에 완료했고, Work 입력 검증이 끝나기 전에 다음 정규 수집이 시작했다. 진단용 Work 루트에서 실제 입력 검증까지만 실행했으며 이벤트를 할당하지 않았다(`pre-report-handoff-420-20261022.json`). 그러나 확장 관측은 전체 원본 만료를 다시 발견했으므로 `strategy-deployed-420-20261022.json`의 결과는 **FAILED_VERIFICATION**이다.

04:03:52 KST 평가가 사용한 원본의 거래정지 피드 발행 시각은 04:01:36이었다. 새 호가를 읽어도 이보다 오래된 필수 증거의 시각을 유지해야 한다. 다음 정규 원본은 약 4초 뒤인 04:03:56에 완료됐다. [Nasdaq의 공식 피드 지침](https://www.nasdaqtrader.com/Trader.aspx?id=TradeHaltRSS)은 분당 1회보다 자주 조회하지 않도록 안내한다. 요청 빈도나 증거 유효기간을 늘려 해결하지 않는다.

실행 가능한 신호가 없고 같은 시장·같은 이전 원본을 잇는 모의 생산자가 이미 수집 중인 경우에만 완료된 새 원본을 최대 15초 기다린다. 새 원본은 기존 선택기가 완료·시장·시점을 검증하고 신호 전체를 다시 구성한다. 기다린 뒤에는 현재 시각으로 세션, 계좌 소유권과 기존 승인·자료 검증을 다시 적용한다. 현재 유효한 진입·위험 축소 신호와 미결 주문 조회는 대기하지 않는다. 생산자가 없거나 미래·잘못된 시작 시각·다른 출처이면 기다리지 않으며, 제한 시간 안에 새 원본이 없으면 기존 만료 차단을 유지한다. 이전 원본 ID·신선한 행 수·실제 대기 시간·새 원본 ID를 별도 진단에 보존한다. 원본 파일, 시각, 120초 기준, 주문 ID 및 원장은 변경하지 않는다.

외부 API 없는 검사로 완료·미완성·미발행·미래·다른 시장 원본, 잘못된 생산자 기록, 시각 역행, 대기 중 계좌·승인·소유권·장 종료 변화와 유효한 매수·매도 및 미결 주문의 무대기를 검증한다. 모의계좌 직접 배정 방식과 기존 배정 방식 모두 동일한 조건을 통과해야 한다. 이 수정도 실제 전략 체결을 보장하거나 증명하지 않는다.
