# 국내 신규상장 종목의 전체 이력 검증 경계

2026-10-26. 이 변경은 정상 연구에 필요한 가격 이력의 시작 경계를 검증한다. 실제 정상 연구 완료·채택·투자 승인·주문·체결과 수익성은 별도 증거다. 원래 계좌·소유권·한도·잠금·연구 예산과 실계좌/자동 실투자 전환 비활성을 유지한다.

## 실제 실패와 확인한 원인 범위

원래 예약으로 시작한 국내 full `20261026T044544_local-scheduler-kr-full`에서 278470.KS, 403870.KQ, 064400.KS, 411080.KQ가 거래일 이력 검증 오류로 실패했다. 검사 시점에 실행은 아직 진행 중이었다. 네 원본은 그대로 보존했고 강제 재실행·예산 초기화는 하지 않았다.

기존 Yahoo 검사는 첫 관측 이후 세션을 확인했지만 KIS 전체 대체 검사는 원래 5년 요청 시작일부터 요구했다. 상장 전인 2021년까지 요구하면 그 뒤 상장한 정상 KIS 시계열도 거절될 수 있다. 이 코드 경로와 합성 반례를 확인했다. 다만 이번 거절 프레임은 확인한 영수증에 보존되지 않아 네 실제 실패의 유일한 원인이라고 확정하지 않는다.

오래된 두 Yahoo 캐시는 2025-09-19가 빠져 있었지만 현재 거절 프레임과 같은 바이트라는 증거는 없다. 공식 [HPSP 거래 공시](https://kind.krx.co.kr/external/2025/09/19/000610/20250919001455/70829.htm)와 [APR 보유변동 공시](https://kind.krx.co.kr/external/2025/09/24/000305/20250924000890/00637.htm)는 당일 거래를 보여준다. 이 날짜를 휴장·전일 무거래로 제외하지 않는다. OHLCV·부분 거래정지·조정 기준이나 공급자 오류 원인까지 입증한 자료는 아니다.

## 원래 요청과 검증할 세션의 구분

새 KR 전용 계약은 이 네 검토 종목에만 적용한다. 이는 자료 검증 목록이며 주문 허용목록·전략 소유권·수량/금액 한도를 넓히지 않는다. 원래 요청 시작일·종료일은 유지하며, 요청이 확인된 최초 정규상장일보다 이를 때만 `required_start`를 그 상장일로 정한다. 처음 보이는 가격을 상장일로 쓰거나 전 종목을 370일로 줄이지 않는다. IPO 첫 유효 세션과 그 이후 원래 종료일까지의 모든 필수 세션을 검증한다. 상장일·거래소·ISIN·증권 종류 불일치, 중간 누락·비세션·잘못된 OHLCV는 계속 거절한다.

KIS 가격과 Yahoo 가격을 섞거나 가격·거래량을 보정하지 않는다. Yahoo도 이 계약을 사용하는 경우 같은 IPO 첫날·전체 세션 경계를 적용한다. 가격 공급자와 KIS 신원 검증 공급자는 따로 기록한다. 원래 가격 수집시각이나 조정 기준이 미확인이면 신원 확인 시각으로 채우거나 KIS 가격으로 이름만 바꾸지 않는다. 단순 출처 문자열·비어 있지 않은 조정 문구·재해시한 딕셔너리는 원래 공급자 요청의 증거가 아니다. 허용된 KIS 전체 대체 경로를 사용하고, 검증된 대체가 없으면 차단한다. 현재 기존 Yahoo getter/CSV에는 새 source-hook 증거 발급을 추가하지 않았으므로 이 네 상장 경계에서는 KIS 전체 대체가 실제 적용 경로다. 지표의 최소 관측 수와 계산식은 그대로이며 199행으로 200일 이동평균을 만들지 않는다.

등록되지 않은 종목이나 요청이 이미 IPO 이후에서 시작하는 경로는 기존 동작을 유지한다. 미국 GEV/SHEL 계약은 KR에 직접 재사용하지 않으며 기존 US 회귀를 보존한다.

## 수집시각·캐시·영수증의 경계

원문을 실제 수집한 10월26일 06:12·06:17·06:28~29의 가용시각을 각 검토 사건에 구분한다. 과거 공시일은 실제 수집일이 아니며 이 새 증거를 04:45 시작의 기존 immutable 연구에 소급하지 않는다. 과거 또는 미래·시각대 없는 cutoff, 해당 분석보다 늦은 증거는 거절한다.

새 수집은 필요한 경우 고정된 공식 KIS 공개 master ZIP을 기본 TLS로 읽는다. 인증정보·계좌·주문 API를 사용하지 않고 redirect·압축 및 해제 크기·중복 member를 제한한다. 공용 master에는 300초 신선도 검사를 적용한다. 새 연구의 프로세스 캐시는 만료된 신원 근거를 새로 수집하지만, 동일 활성 연구의 선택 원문은 원래 검증 시각·가격·공급자·해시를 고정한다. 시간 경과만으로 선택 원문이나 가격 관측시각을 바꾸지 않는다. 다른 분석 cutoff·종목·시장·기간은 재검증한다.

정형 KR 영수증은 원래 요청, 상장 후 필수 시작일, 공식 사건·현재 master 신원, 실제 가격 공급자·조정 기준·시계열 SHA를 결합해 다시 구성한다. 저장된 딕셔너리의 상태 문구만 신뢰하지 않는다. `VERIFIED_RETRIEVED_SERIES`도 당시 수정본 가용성이나 실시간 주문 시세의 증명이 아니며 `historical_vintage_verified=false`를 보존한다.

## 검증과 남은 실제 조건

외부 API 없는 fixture는 네 동일증권·상장사건·가용시점, 미래/누락/잘못된 날짜, 거래소·종목·보통주 불일치, 원문·영수증·캐시 변조, IPO 첫날 및 9/19 누락, 지표 관측 수 부족, Yahoo의 관측시각·조정 기준 미확인, 대체 실패와 기존 US 동작을 검증한다. 최신 main 통합 후 관련 6파일 380개가 통과했다. 선행 영향 묶음 329개·독립 표적 26개·별도 네 종목 Mock 16개 등은 범위가 겹치며 중간 SHA 검사와 합산하지 않는다. 마지막 검토에서는 원래 Yahoo 104를 보존하고 실제 KIS Mock 조회의 105 전체 시리즈를 쓰는 반례로 출처 재라벨 우회가 닫혔는지 확인했다. 최종 정확 head CI·병합·배포와 기존 승인/원장 보존은 별도 영수증으로 판정한다.

배포 후 새 시각에 수집한 실제 전체 가격 시리즈, 필수 일자·출처·조정 기준·영수증 검증이 필요하다. 읽기 전용 가격 진단도 정상 그래프 완료나 채택이 아니다. 이후 원래 예산 안의 정상 연구·재개, 완료 원본 소비, 유효한 원래 BUY/SELL 승인과 KIS 모의 체결을 각각 확인한다. 정상 체결·실제 비용·반복 미래 성과·실투자 준비 완료를 이 수정만으로 선언하지 않는다.
