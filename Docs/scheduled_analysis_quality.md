## 조사 근거와 적용

[공식 Scheduled tasks 문서](https://learn.chatgpt.com/docs/automations)는 웹 예약의 로컬 폴더 접근 불가, 지속 지침의 예약 본문 저장, 일반 대화에서 시험 후 초기 실행 검토를 안내한다. 데스크톱 모델 선택 설명을 클라우드 도구 지원으로 해석하지 않는다.

[공식 Prompting 문서](https://learn.chatgpt.com/docs/prompting)는 목표·맥락·출력·경계를 명확히 하고 중요한 결과의 최종 검증을 요구하도록 안내한다. 이를 투자분석에 맞게 다음과 같이 적용했다.

| 문제 | 적용한 통제 | 확인 방법 |
|---|---|---|
| 오래된 대화가 최신 계좌로 취급됨 | 매 실행 재조회, 권고와 체결 분리 | 관측시각 및 현재 수량 대조 |
| 자료 조회 실패가 시장 악재로 해석됨 | 조회 실패·자료 부재·투자 판단 분리 | 실패 이유와 제한되는 판단 확인 |
| 중복 조회에 조사 자원 소진 | 해당 시장 JSON·보유주 우선, 불일치만 HTML 대조 | 보유주 누락 수 확인 |
| 긴 분석 중 가격 유효기간 경과 | 시작·완료시각, 만료 시 재확인 또는 조건부 하향 | 최종 행동의 가격 유효성 확인 |
| 계좌 제약·현금 배분 계산 오류 | 도구 검산, 음수 잔액·중복 재원 검사 | 비용 후 현금 및 비중 재계산 |
| 모바일 핵심 결론이 긴 본문 아래 숨음 | 결론 직후 5열 모바일표 | 출력 순서·열 수 확인 |

## 검증 기준과 한계

문서 테스트는 전체 프롬프트의 14,000자 미만 유지, 한국어·시장별 핵심 요구, 품질 규약 포함을 검사한다. v3는 별도 첨부 없이 근거·위험예산·성과 검증을 수행하도록 규칙을 본문에 포함해 상한을 조정했다. 이는 실제 모델 답변 정확도나 투자수익률을 검증하는 테스트가 아니다.

실제 출력에서는 보유주 분석 수/확인 수, 조건 완결 행 수/대상 행 수, 추가 현금 0원+4개 양수 시나리오, 산술·출처 검증 결과를 확인한다. 자료가 없으면 확인 불가를 정직하게 남기는 것이 합격 조건이며 수치를 만들어 완성도를 채우면 실패다. 동일 입력에 대한 개선 전후 답변을 비교하지 않았으므로 정량적 성능 향상률은 주장하지 않는다.

클라우드 예약 수정은 해당 예약의 prompt만 갱신한 뒤 재조회하여 본문 일치와 일정·활성화·대상 대화 보존을 확인한다. 기존 분석 중 새 시험 요청이 거절되면 실패를 기록하고 중복 전송하지 않는다. 예약 실행 성공과 최종 분석 품질을 별개로 검증한다.

## v3 공유 대화 검토

대상: [공유 대화](https://chatgpt.com/s/t_6aac11167c6c8191b7db8d7629f2a320).
공개 페이지는 제목만 반환했으므로 연결된 계정의 동일 제목 「스크린샷 분석 가이드 작성」 대화 본문을 검토했다. 연결된 Word·ZIP 및 스크린샷 원본을 모두 검사한 것으로 주장하지 않는다.

| 원안 주제 | v3 적용 | 별도 예약 판단 |
|---|---|---|
| 아이디어 발굴 | 적격 후보 0개 허용·부분 스크리닝 범위 공개 | 일일 분석에 통합 |
| 기술적 분석 | 지표 설정·수정주가·봉 완성 여부·실제 계산 구분 | 일일 분석에 통합 |
| 뉴스 영향 | 실적·현금흐름·기업가치 및 반영 시차로 연결 | 일일 분석에 통합 |
| 백테스트 | 데이터·실행·비용·거래내역·표본 밖 검증 없으면 미산출 | 연구 규칙·데이터 준비 전 신규 예약 보류 |
| 위험관리 | 조건부 수량·계좌 잔여 위험예산·ETF 중복·갭 위험 검산 | 일일 분석에 통합 |
| 매매일지 | 체결기록이 있을 때만 결과와 계획 준수 분리 | 비공개 체결기록이 없어 신규 예약 보류 |
| 당일 계획 | 기존 시각·모바일표·추가 현금 시나리오 유지 | 기존 예약 재사용 |
| 스크리너 | 조사 범위·누락·점수 산식, 점수와 확률 구분 | 일일 분석에 통합 |
| 통합·결과 검증 | 최종 초안의 오류 위치·근거·영향·수정 및 금요일 최근 5회 품질 복기 | 동일 실행 내 수행, 별도 중복 예약 없음 |

자료 미확인을 0으로 간주하거나 모든 조건부 수량 제안을 없애지는 않는다. 사용자가 요구한 외부 현금 가능성은 가정별 계획으로 유지하되 확정 주문과 구분한다. 같은 모델의 자기검증은 독립 외부 검증이 아니며 별도 성과 검증도 아니다.

금요일 점검은 각 시장 현지 금요일의 기존 실행에 포함된다. 접근 가능한 보고서만 세며 조회 불가 시 미실시로 표시한다. 분석기가 예약·프롬프트·코드를 자율 수정하거나 새로운 감시를 약속하지 않는다.
