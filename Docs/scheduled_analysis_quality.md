# 예약 투자분석 품질 개선 — 2026-09-11

## 운영 결정

국내·미국 기존 ChatGPT 클라우드 예약을 유지하고 각 예약에 전체 프롬프트를 저장한다. 로컬 PC·로그인 화면·좌표 조작에 의존하는 전송 예약을 추가하지 않는다. 예약 도구의 모델·추론 필드가 없으므로 GPT-5.6 Sol/xhigh를 설정했다고 표시하지 않는다. 국내·미국 외의 리포트 생산 예약은 변경하지 않는다.

- 국내: Asia/Seoul 월~금 13:00.
- 미국: Asia/Seoul 월~금 00:00.
- 예약 시각은 실행 시작 목표이며 결과 완료 시각을 보장하지 않는다.
- 미국 일정은 미국 거래일 월~금과 다르다. KST 월요일 자정은 미국 일요일, KST 토요일 자정은 미국 금요일이다. 원래 요청을 보존했으며 미국 금요일 장중 분석을 포함하려면 별도 일정 변경이 필요하다. 휴장·조기폐장·서머타임은 실행마다 확인한다.

## 조사 근거와 적용

[공식 Scheduled tasks 문서](https://learn.chatgpt.com/docs/automations)는 웹 예약의 로컬 폴더 접근 불가, 지속 지침의 예약 본문 저장, 일반 대화에서 시험 후 초기 실행 검토를 안내한다. 데스크톱 모델 선택 설명을 클라우드 도구 지원으로 해석하지 않는다.

[공식 Prompting 문서](https://learn.chatgpt.com/docs/prompting)는 목표·맥락·출력·경계를 명확히 하고 중요한 결과의 최종 검증을 요구하도록 안내한다. 이를 투자분석에 맞게 다음과 같이 적용했다.

| 문제 | 적용한 통제 | 확인 방법 |
|---|---|---|
| 오래된 대화가 최신 계좌로 취급됨 | 매 실행 재조회, 권고와 체결 분리 | 관측시각 및 현재 수량 대조 |
| 자료 조회 실패가 시장 악재로 해석됨 | 조회 실패·자료 부재·투자 판단 분리 | 실패 이유와 제한되는 판단 확인 |
| 중복 조회에 조사 자원 소진 | 해당 시장 JSON·보유주 우선, 불일치만 HTML 대조 | 보유주 누락 수 확인 |
| 긴 분석 중 가격 유효기간 경과 | 시작·완료시각, 만료 시 재확인 또는 조건부 하향 | 최종 행동의 가격 유효성 확인 |
| 계좌 제약·현금 배분 계산 오류 | 도구 검산, 음수 잔액·중복 재원 검사 | 비용 후 현금 및 비중 재계산 |
| 모바일 핵심 결론이 긴 본문 아래 숨음 | 결론 직후 5열 모바일표 | 출력 순서·열 수 확인 |

## 검증 기준과 한계

문서 테스트는 전체 프롬프트의 12,000자 미만 유지, 한국어·시장별 핵심 요구, 품질 규약 포함을 검사한다. 이는 실제 모델 답변 정확도나 투자수익률을 검증하는 테스트가 아니다.

실제 출력에서는 보유주 분석 수/확인 수, 조건 완결 행 수/대상 행 수, 추가 현금 0원+4개 양수 시나리오, 산술·출처 검증 결과를 확인한다. 자료가 없으면 확인 불가를 정직하게 남기는 것이 합격 조건이며 수치를 만들어 완성도를 채우면 실패다. 동일 입력에 대한 개선 전후 답변을 비교하지 않았으므로 정량적 성능 향상률은 주장하지 않는다.

클라우드 예약 수정은 해당 예약의 prompt만 갱신한 뒤 재조회하여 본문 일치와 일정·활성화·대상 대화 보존을 확인한다. 기존 분석 중 새 시험 요청이 거절되면 실패를 기록하고 중복 전송하지 않는다. 예약 실행 성공과 최종 분석 품질을 별개로 검증한다.
