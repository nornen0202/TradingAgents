# 120초 실행 유효기간에 맞는 관측 해상도

2026-10-19 미국 정규장 배포 검증에서 소비자 호출은 완료 후 약 0.06초에 시작했지만, 30종목 모두 5분봉 시각을 가지고 있어 완료 시점에 이미 120초를 넘겼다. 가장 오래된 관측은 약 219초였다. 이는 보고서 전달 시각으로 원래 시세 시각을 갱신해서 해결할 수 없는 문제다.

실행 오버레이는 실제 `1m` 자료를 요청하여 새로 계산한다. 미국 KIS 분봉 요청의 `NMIN`도 이 값에 따라 1로 전달된다. 원래 시세 시각과 계약, 신호 유효기간은 보존한다. 국내 KIS 분봉은 원래 1분 자료이며 동일한 실행 메타데이터로 정렬한다. 뉴스의 선행 수집과 즉시 소비자 호출을 함께 적용한다.

오버레이는 각 종목의 최신 실행·차트 화면을 이미 생성하므로, 포트폴리오 처리 후 같은 화면을 한 번 더 생성하던 작업을 생략한다. 전체 리서치에서 새 추천을 기록한 뒤 화면을 갱신하는 경로는 유지한다. 1분 자료가 없거나 오래되면 기존 차단을 유지하며 5분 자료의 시각을 바꾸거나 미래·미확인 자료를 인정하지 않는다. 더 촘촘한 자료에서도 전체 세션 VWAP를 구성할 데이터가 부족하면 해당 품질 제한을 그대로 표시한다.

검증은 분 경계에서 벗어난 새 1분 관측이 원래 120초 유효기간 안에 소비되는지, 정확히 만료되면 거절되는지, 최신 차트 파일이 유지되는지 확인한다. 실제 운영에서는 완료 원본의 모든 시세 시각과 `execution-handoff/latest.json`을 대조한다. 실행 신호·명시적 주문 제안이 없는 원본으로 매매를 만들어 내지는 않는다.
