# 매일 바뀌는 분석 대상 — 한국·미국 각각 최대 30개

Daily Codex Analysis의 미국·국내 운영 설정에 자동 선정을 적용했다. 기존 고정 목록은 후보를 찾는 출발점으로 남지만, 목록 전체가 매일 정밀 분석을 받지는 않는다. 계좌 보유 종목은 반드시 포함하며 나머지 자리에 근거가 좋은 관심·신규 후보를 배치한다. 종목별 Sol 분석 모델·분석가 수·토론 수준은 줄이지 않는다.

## 선정 순서

1. **최신 계좌 조회:** 기존 계좌 연동으로 보유 종목을 읽는다. 한국 종목의 숫자 코드와 `.KS`/`.KQ` 표기는 같은 종목으로 계산한다. 계좌 조회가 실패하거나 보유 종목만 상한을 넘으면 임의로 종목을 빼지 않고 실행을 중단한다. 서로 다른 시장의 계좌가 섞여도 중단한다.
2. **이전 분석 확인:** 운영 아카이브의 `runs/YYYY/run-id/run.json`에서 최근 30일의 같은 시장·프로필 분석을 읽는다. 최대 2,000개 실행 기록을 검사하며, 완료 시각이 미래인 기록·장중 갱신·smoke·검증 실패 판단은 선정 근거에서 제외한다. 이전 판단·매수 조건·위험 대응과 자료 품질을 사용한다. 아직 관측되지 않은 수익을 학습하거나 AI 확신도를 수익 확률로 바꾸지 않는다.
3. **새 후보 조사:** [yfinance의 공식 Screener](https://ranaroussi.github.io/yfinance/reference/api/yfinance.screen.html)로 시장 전체의 11개 업종별 시가총액 상위 후보와 거래량 상위 후보를 조사한다. 기존 관심 목록·스캐너·이전 분석 종목도 함께 비교한다. Screener의 종목 코드 검색 제약 때문에 누락된 기존 후보는 일봉을 일괄 조회한다. 업종 미확인 기존 후보는 최대 60개까지 별도 기업정보로 보완한다.
4. **기초 자료 검사:** 보유하지 않은 종목은 미래·7일 초과 가격, 확인되지 않은 통화, 낮은 유동성, 하루 20% 초과 등락을 걸러 낸다. 유동성은 현재 가격×평균 거래량을 이용한 근사치로, 기본 문턱은 미국 일평균 1천만 달러·한국 20억원이다. 이는 체결 가능 금액이나 실제 거래대금 보장이 아니다.
5. **조사 우선순위:** 최근 분석의 평가·진입 조건과 현재 가격의 거리·50/200일 평균 대비 추세·유동성·다가오는 실적 일정을 함께 본다. 이전 판단의 영향은 시간이 지날수록 줄고, 과열 구간·위험 축소 의견·자료 부족은 감점한다. 실적 예정일은 추가 조사 사유이며 매수 신호가 아니다.
6. **안정성과 탐색:** 보유하지 않은 신규 후보 조사에 최대 3자리를 우선 배정하고, 이후 근거 점수로 채운다. 직전 완료 목록이 있으면 비보유 신규 편입은 하루 최대 6개다. 확인된 동일 업종은 보유 종목을 포함해 최대 8개를 원칙으로 삼되, 보유 종목은 이 제한보다 우선한다. 업종이 미확인인 종목은 그 사실을 표시하며 분산을 달성했다고 간주하지 않는다.

보유가 14개라면 비보유 정밀 분석 자리는 최대 16개다. 후보 조사는 최대 160개까지 하지만, 여러 분석가가 수행하는 정밀 분석은 **보유 포함 최대 30개**다. 문턱을 충족하는 후보가 적거나 교체 제한이 걸리면 30개보다 적게 분석한다. 더 작은 수동 상한·smoke에서도 보유 종목을 누락하지 않으며 30개를 넘지 않는다. 수동 `--tickers`는 후보 입력을 바꾸며 보유 종목 필수 규칙을 해제하지 않는다.

## 자료 장애와 장중 동작

- 공급자 오류는 개별적으로 기록하고 연속 세 번의 스크리닝 오류 후 추가 요청을 중단한다. 보관된 가격을 쓸 때도 같은 날짜 제한을 적용하고 출처를 `archived_quote`로 표시한다. 자료를 확보하지 못한 비보유 종목으로 빈자리를 강제로 채우지 않는다.
- 과거 날짜를 명시한 재현 실행은 현재 시장 스크리닝을 섞지 않도록 자동 선정을 거절한다. 별도 설정에서 자동 선정을 끄고 당시 종목 목록을 제공해야 한다. 이 기능은 과거 시점 정확성을 보장하는 백테스트용 종목 구성기가 아니다.
- 선택된 종목의 정밀 분석이 누락·실패하면 완료 범위 검증이 실패한다. 의도적으로 선정하지 않은 후보는 분석 누락으로 취급하지 않는다.
- 장중 overlay는 새 종목을 다시 선정하지 않고 최근 완료된 일일 목록을 유지한다. 예전 목록이 더 크다는 이유로 새 30개 이하 목록을 덮어쓰지 않는다. 새로 보유하게 된 종목이 일일 분석에 없으면 기존 보유 누락 방지 절차가 작동한다.
- 공개 페이지에서는 기존 공개/비공개 종목 경계를 유지한다. 계좌번호·수량·평가금액을 선정 기록에 추가하지 않는다.

## 결과 확인과 설정

각 실행 폴더에 `universe_selection.md`와 `universe_selection.json`이 저장된다. 선정·제외 이유, 적용 상한, 이전 목록, 후보별 근거·자료 시각·출처·점수·업종을 확인할 수 있다. 실행 보고서 페이지에도 공개 대상 종목의 선정 이유가 표시된다. 제외는 매도 지시가 아니다.

운영 설정은 `config/scheduled_analysis.toml`과 `config/scheduled_analysis_korea.toml`의 `[universe]`에 있다. 두 설정 모두 `enabled=true`, `max_tickers=30`이다. 기본 예제는 계좌 연결 전 실행을 막지 않도록 `enabled=false`다. 상한을 30보다 크게 설정하면 오류가 나며, 수동 일일 상한을 높게 입력해도 자동 선정의 30개 제한은 유지된다.

## 검증 범위

실제 운영 아카이브에서 미국 43개·한국 46개 종목의 과거 판단을 읽었고, 최신 시세 조사와 결합해 검증했다. 저장된 완료 계좌 목록 기준 미국 보유 14개·국내 보유 13개가 모두 유지됐다. 업종 보강 후 미국은 114개 후보 중 28개, 국내는 115개 후보 중 30개를 선정했다. 미국은 업종·교체 제한을 완화해 억지로 채우지 않았다. 한국 일부 종목 가격과 양 시장 일부 업종 정보는 확인되지 않아 해당 상태를 기록했다.

이 검증은 **저장된 계좌 목록과 실제 최신 시장 자료**를 사용한 선정 시험이며 새 실계좌 조회나 58개 종목의 전체 LLM 분석을 실행한 것은 아니다. 계좌 오류·30개 초과 보유·한국 별칭·시장 분리·과거/미래 자료·선정 누락·업종/교체 제한·장중 목록 유지와 공개 정책은 자동 테스트로 검증한다. 점수 가중치와 제한은 설명 가능한 초기 운영 정책이며, 수익률 우월성이 입증된 최적화 결과가 아니다.

전체 회귀 검증은 1,009개 테스트·78개 하위 테스트 통과, 1개 건너뜀이다. 정적 검사와 기존 모바일 화면 360/390/430px 검증도 통과했다. 최종 원격 CI 결과는 PR에 기록한다.
