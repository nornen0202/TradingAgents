# 미국 시계열 내부 거래일 누락 복구 검증

2026-10-23 KST의 별도 공개 시세 조회에서 기존 실패 종목의 상태를 다시 확인했다. 조회는 연구·모델·계좌·주문 호출이나 운영 캐시 갱신을 수행하지 않았다. 가격 원문은 한 공급자의 전체 응답으로 보존했고 행 보정·공급자 혼합을 하지 않았다.

## 실제 원본과 재현

DELL의 2021-10-22~2026-10-22 Yahoo 시계열은 XNYS 거래일 1,255개와 일치했다. 모든 행의 숫자·OHLC 범위·날짜·중복도 별도 오프라인 검사에서 통과했다. 이 원문 SHA-256은 `e5da535e6ef0f7652a5976edf44495c0e377ae171a2f6e7a004d376662481af9`다. 현재 수집본을 과거에 실제 알려졌던 수정주가라고 해석하지 않는다.

같은 조회에서 ETN·RHHBY·XOM·BRK-B·PM은 10월21일 봉이 없었다. 최신 10월22일 봉이 존재해도 내부 누락은 남는다. CVX 최신 봉은 시가 228.8574981689453, 고가 228.8350067138672로 기존 검증이 거절했다. GEV의 첫 관측 2024-03-27을 정규 상장일이나 동일 증권의 입증으로 사용하지 않는다. 이 조회로 짧은 상장 이력 계약이나 OTC의 KIS 지원을 변경하지 않았다.

ETN 원문 `6eff94e897890016625ac79338130106b3ea4ac5601b030c11143802c67c90de`를 기존 `validate_with_us_fallback`에 넣은 네트워크 없는 재현은 예상 거래일 1,255개 중 1,254개를 그대로 승인했고 KIS 복구를 호출하지 않았다. 원본 재현 영수증은 운영 검증 디렉터리의 `yahoo-session-hole-reproduction-20261023.json`이다. 새 공개 조회는 `G:/TradingAgentsData/migration-audits/remaining-us-history-20261023/`에 있고, 모든 행 검사는 `yahoo-probe-all-row-audit-20261023.json`에 있다. 기존 `validate_daily_bars`의 검사는 최신 봉에 대한 검사이며 전체 행 검사와 구별한다.

## 변경 범위

미국 KIS 연구 복구가 원래 활성인 경로에서 Yahoo가 실제 관측한 첫 봉부터 마지막 봉까지 XNYS 완료 거래일의 내부 누락을 검사한다. 최신 완료봉 부재의 기존 검사도 유지한다. 내부 누락은 기존 KIS 전체 시계열 로더로 전달하고 원래 출처 고정·전체 범위·시간/페이지 상한·조정 기준·원문 검증을 적용한다. 복구할 수 없으면 오류를 유지하며, 누락 행을 만들거나 다른 공급자의 행으로 채우지 않는다.

기존 Yahoo의 선두 이력 계약과 KIS의 5년 전체 이력 계약은 바꾸지 않았다. 첫 관측일을 상장일로 추정하지 않는다. 정상 연속 시계열과 주말·휴장 구간은 값과 공급자를 보존한다. 결측 날짜가 `NaT`가 됐을 때 예외 대신 기존 날짜 제외 검증으로 이어지도록 했다. 제외 결과 내부 거래일이 빠지면 동일 복구를 요구한다.

## 검증과 운영 제한

외부 API 없이 정상 연속 이력, 주말, 기존 선두 단축 이력, 내부 누락, 미래·결측·잘못된 날짜, 복구 부재, 원문 불변 및 기존 출처 고정·전체 복구 계약을 검사했다. 관련 5개 파일의 오프라인 검사 149개와 Ruff/diff 검사가 통과했다. 독립 검토에서 요청 시작일 이전 봉만 있는 응답의 역순 달력 범위 회귀를 발견했고, 기존 최신 봉 복구로 넘기도록 수정하고 회귀 검사를 추가했다. 초기 실패와 수정 후 결과는 별도로 보존하며 테스트 수를 합산하지 않는다.

공유 무결성 변경에 대해 baseline·strategy·walk-forward의 별도 78개 검사도 통과했다. 저장된 실제 8종목 원문을 새 함수에 재생한 오프라인 검증은 DELL 1,255행을 값 변경과 복구 호출 없이 통과시켰다. 나머지 7종목은 내부 누락 또는 기존 최신 OHLC 오류로 전체 대체를 요구했고, 대체 로더를 `None`으로 Mock하면 거절했다. `yahoo-session-hole-staged-replay-20261023.json`은 이 결과를 보존한다. 이 검사는 실제 KIS 복구 성공이나 다음 정상 연구 완료를 증명하지 않는다.

이 문서 작성 시 변경은 격리 브랜치에서 검증 중이다. 최종 head CI·병합·배포와 실제 정상 연구 채택은 별도 확인한다. 원래 연구 예산·승인·주문 한도·원장·계좌 소유권·잠금은 변경하지 않았고 소진된 연구를 강제 재실행하지 않았다. 정상 전략 체결과 국내 검증 왕복의 미충족 상태, 실제 비용·순손익 null 및 실계좌/자동 실투자 비활성을 유지한다.
