# 국내 전체 시계열 복구와 휴장 구분 검증

## 원본 근거

2026-10-23 06시 정상 국내 연구의 29개 달력 생성 경합은 PR445에서 분리해 수정했다. 남은 267260.KS의 오류는 별도 자료 검증이다. 해당 실행이 실제 사용한 Yahoo 캐시는 거래 기준일 2026-10-22까지 1,220행이며, SHA는 `ffa5380cbd8cbdf2e6a7e026217d6b05a38588ddc897099e1b8ebae2f667ac8d`다. SK하이닉스·삼성전자·두산에너빌리티의 같은 기간 캐시도 같은 네 날짜가 없었다. 이 사실만으로 모든 날짜를 휴장 또는 모든 날짜를 공급자 오류로 간주하지 않았다.

새 읽기 전용 KIS `chk-holiday` 조회는 2022-01-03·2022-05-09·2025-09-19를 개장, 2026-06-03을 휴장으로 반환했다. 원문·조회 시각·SHA는 `G:/TradingAgentsData/migration-audits/kis-kr-holiday-diagnostic-20261023/`에 보존했다. 운영 달력 캐시는 수정하지 않았다. 현재 수집한 응답을 과거 수집 증거로 소급하지 않는다.

선거일은 [중앙선관위 공식 일정](https://www.nec.go.kr/site/nec/main.do)의 2026-06-03과 일치한다. [KRX KOSPI 휴장 규칙](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T1.jsp)은 정부 공휴일·선거일을 휴장으로 설명하고, [KRX 운영 공지 목록](https://strn.krx.co.kr/corebbs5/BHPSTRN0401/list)의 2026-06-01 공지도 6월3일을 확인한다. KRX 두 페이지의 검색 색인 본문과 별개로 직접 열람은 403이었다. 이 한계를 숨기지 않으며 선관위 직접 본문 및 KIS 원문과 함께 판단했다. 다른 날짜의 선거일이나 휴장을 추정하지 않는다.

기존 읽기 전용 KIS 국내 일봉 로더의 별도 진단은 같은 5년 범위에 1,223행을 반환했다. SHA는 `c0b896da1f68c4e76c17f91aa736c4df4037773c8f621d255d14b665962dd81e`다. 개장일 세 개는 조회 시계열에 있고 휴장일은 없다. 이 진단 저장물은 검증 뒤 CSV이며 페이지별 원본 HTTP 응답·헤더는 별도로 확보하지 않았다. `kis-kr-whole-history-267260-primarykeys-20261023/`에 보존했다. 앞선 worktree 기본 인증 경로의 UNAVAILABLE는 자격 정보 경로 부재였고 공급자 장애로 판정하지 않았다. 정상 운영 설정·계좌·주문·연구 예산은 변경하지 않았다.

## 변경

확인된 단일 휴장일 2026-06-03을 기존 보완 달력에 추가한다. 날짜 규칙을 미래 선거에 일반화하지 않고 기존 제헌절 보완은 유지한다. 나머지 세 날짜는 요구 거래일로 남긴다.

원래 KIS 연구 복구가 켜진 국내 경로는 첫 가격 보고 전 기존 5년 지표 입력을 검증한다. 내부 또는 최신 필수 거래일이 빠지면 기존 KIS 전체 로더를 사용하며 같은 종료일의 짧은 시계열로 대체하지 않는다. 가격 보고의 요청 창은 유지하고 이후 지표·차트는 한 번 선택한 원본 스냅샷을 재사용한다. 행 보정·보간·공급자 혼합·370일 계산 창 축소를 하지 않는다. 기존 Yahoo 선두 단축 이력 계약은 유지하지만 첫 관측일을 상장일이나 완전 이력 증명으로 쓰지 않는다.

전체 연구 복구는 `require_complete=True`로 요청 범위의 실제 거래일 집합을 검증한다. 최근 완료 거래일 확인용의 기존 `require_end` 경로는 그 목적을 유지한다. 유효하지 않은 전체 응답은 성공 캐시에 넣지 않고, 부분 캐시를 전체 입력으로 재사용할 때도 재검증한다. 캐시 TTL과 시점은 연장하지 않는다. 잠금은 캐시 복사/등록만 보호하며 네트워크 호출은 밖에서 수행한다.

검증된 KIS 국내 스냅샷은 provider, KRX, 수정주가 인자 `FID_ORG_ADJ_PRC=0`, 요청 범위, 실제 수집 시각, 관측 수와 선택 시계열의 CSV 직렬화 해시를 보존한다. 기존 미국 MODP=1 영수증 조건은 유지한다. Yahoo 등 증거가 부족한 경로를 검증 완료로 승격하지 않으며, 과거 원본 연구에 새 영수증을 소급해서 추가하지 않는다.

## 검증 범위와 미충족

관련 8개 파일 오프라인 검사 316개, Ruff와 diff 검사가 통과했다. 정상·빈·누락·미래·잘못된 날짜, 불완전 전체 대체 거절, 첫 가격/이후 지표의 단일 5년 원본, 캐시 만료 후 원본 보존, Yahoo 캐시 오염 방지와 원래 미국 검증을 포함한다. 초기 5실패/75통과는 짧은 기존 복구 fixture와 오류 문구 계약 및 단일 세션 달력 범위를 드러냈다. 전체 범위 fixture와 실제 거래일 필터를 보강해 해결했고 실패 수치를 최종 성공에 합산하지 않는다. 단일 세션 달력의 생성 여유 범위는 가격 날짜 범위를 확장하지 않는다.

저장된 실제 두 공급자 시계열의 네트워크 없는 재생은 KIS 1,223행 전체 대체, 동일 스냅샷 고정, 200일 SMA 897377.5를 원본 계산과 대조했다. 원래 공급자 수집 시각이 저장 CSV에 남지 않았으므로 이를 새로 만들어 넣지 않았다. `kr267260-recovery-replay-20261023/receipt.json`은 값/고정 검증이며 정상 연구 채택이나 검증된 원래 시각 영수증을 주장하지 않는다.

최종 head CI·배포·다음 기존 예약 연구의 실제 완료는 별도로 확인한다. 이 변경으로 원래 승인·수량·가격·손실·소유권·공유 잠금·원장·시세 120초·재시도 예산은 완화하지 않는다. 정상 BUY/SELL 체결과 국내 별도 왕복, 실제 비용·정산·반복 표본은 여전히 별도 미충족 항목이다. 실제 비용과 순손익은 미확인 시 null이며 실계좌/자동 실투자는 비활성이다.
