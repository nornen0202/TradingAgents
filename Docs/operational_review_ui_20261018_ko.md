# 기존 운영과 투자 검토 화면 연결

기존 TradingAgents 분석·실행 판단·성과 원장을 같은 로컬 화면에서 읽습니다. 별도 투자 Workbench 프로젝트는 만들지 않았습니다. 화면은 읽기전용이며 실계좌 주문을 전송하지 않습니다.

## 화면 실행

```powershell
python tools/serve_investment_review.py --archive-dir C:/TradingAgentsData/archive --tracker-db C:/TradingAgentsData/archive/performance.sqlite --tracker-db C:/TradingAgentsData/archive/paper/kr.sqlite --tracker-db C:/TradingAgentsData/archive/paper/us.sqlite --paper-status C:/TradingAgentsData/archive/paper/status.json --experiment-registry C:/TradingAgentsData/archive/experiments.sqlite --port 8766
```

브라우저에서 `http://127.0.0.1:8766/`를 엽니다. 서버는 로컬 컴퓨터에서만 접근할 수 있습니다. 기존의 단일 실행 폴더 지정도 계속 지원합니다.

- **현재 운영 따라가기**: 1분마다 종목별 최신 완료 분석과 모의 상태를 다시 읽습니다. 한국과 미국의 마지막 실행이 서로 덮어쓰지 않습니다.
- **기준 시각 변경**: 따라가기가 해제됩니다. 그 시점까지 완료된 분석과 관측·확정·정산된 기록만 표시합니다. 이후 생긴 차트·체결·실험 결과가 과거 화면에 섞이지 않습니다.
- **원본 실행·연구 완료 시각**: 새 시세를 읽었다고 원래 연구 판단의 시각을 갱신하지 않습니다. 차트가 최신이어도 과거 판단은 당시 판단으로 표시합니다.
- **지속 모의매매 운영**: 운영 점검, 마지막 실제 시세 관측, 마지막 내부 모의체결 시각을 따로 표시합니다. 휴장 중 운영 점검만 실행되면 체결 시각이 갱신되지 않습니다.
- **실험 카드**: 기존 규칙과 AI 규칙, 대상·연구/미래 관측 기간·자본·비용·규칙 해시를 확인합니다. 완료된 미래 관측이 없으면 수익률을 만들어 표시하지 않습니다.
- **자연어 조건 초안**: 숫자와 조건을 명시하면 기존 스캐너 형식으로 변환합니다. 임계값이 빠지거나 지원하지 않는 지표가 섞이면 조건 전체를 보류합니다. 화면에서 초안을 저장·동결하거나 자동매매를 활성화하지 않습니다.

예시: `거래대금 100억원 이상 그리고 전일 대비 거래량 1.5배 이상 그리고 거래정지 제외`. `거래량이 많은 종목`처럼 수치가 없는 입력에는 임계값을 임의로 채우지 않습니다. 자유로운 자연어 전체를 이해하는 LLM이 아니라 검증 가능한 제한 문법을 사용합니다.

## 기존 분석의 차트를 지금 보완하기

```powershell
python tools/refresh_investment_review.py --archive-dir C:/TradingAgentsData/archive --ticker AAPL --tracker-db C:/TradingAgentsData/archive/performance.sqlite
```

종목 이름은 보관 폴더의 이름을 사용합니다. `--ticker`를 반복하거나 생략하면 최신 완료 분석의 모든 종목을 대상으로 합니다. 이 명령은 기존의 날짜 검증을 거치는 OHLCV 로더를 사용하며, 실제 조회한 현재 시각을 관측 시각으로 기록합니다. 원본 분석·계약·실행 manifest를 변경하지 않습니다. 기존 차트가 있으면 원본을 보존한 채 별도의 시각별 vintage를 추가합니다. 빈 응답·미래·잘못된 날짜 자료는 차트로 발행하지 않습니다.

예전 분석에 없던 차트를 지금 수집했다면 예전 시점 재생에서는 보이지 않습니다. 현재 화면에는 최신 완료 봉과 원본 판단이 함께 보입니다. 현재의 일봉은 실시간 주문 가능 시세를 뜻하지 않습니다.

옛 실행·계약 파일에 수집 시각이 빠져 현재 화면에서도 판단·계획 가격이 보이지 않는 경우에는 외부 조회 없이 원본을 **지금 재관측**할 수 있습니다.

```powershell
python tools/refresh_investment_review.py --archive-dir C:/TradingAgentsData/archive --reobserve-only --tracker-db C:/TradingAgentsData/archive/performance.sqlite
```

원본 실행·시세·만료 시각은 유지하고, 실제 현재 수집 시각과 `reobserved_archive` 출처만 별도 checkpoint에 기록합니다. 화면에는 “현재 재관측한 과거 기록”이라고 표시합니다. 재관측 이전 과거 조회에서 없던 판단이 생기지 않으며, 오래된 시세·만료된 계획이 최신 실행 자격을 얻지 않습니다. 검증할 수 없는 원본 시각은 계속 제외합니다. 같은 원본을 다시 관측해도 첫 관측을 보존합니다.

## 운영 연결의 보완점과 경계

1. 장중 실행만 갱신하는 overlay에서도 차트·이벤트·근거 원본을 복사하고 원래 시각을 보존합니다. 기존에는 이 자료가 빠질 수 있었습니다.
2. 기관 분석팩 생성 실패와 별개로 이미 수집한 SEC·DART 이벤트를 저장합니다. 실패한 선택 기능이 정상 수집한 이벤트를 지우지 않습니다.
3. 추천 원장 기록 뒤 같은 실행의 로컬 HTML을 다시 생성해 추천→의도→체결→회고 연결을 표시합니다. 공개 사이트에는 개인 체결·계좌 원장을 복사하지 않습니다.
4. 빈 차트·선택 렌더링 실패는 `analysis.json`에도 남깁니다. 화면도 자료 없음·시각 미검증을 표시합니다.
5. 공개 보고서는 원자료 재배포 권한이 확인된 경우에만 차트를 표시합니다. 권한이 없거나 차트가 없을 때는 로컬 확인 안내를 표시합니다.
6. 로컬 HTTP API는 GET만 지원합니다. 자연어 초안과 실험 조회도 원장·계좌·조건 설정을 변경하지 않습니다. 모의 운영 상태는 경로·계좌번호·현금·잔고 없이 상태와 시각·건수만 전달합니다.

설치와 자동 실행의 활성화 상태, 공급자 연결 성공 여부, 실제 모의 체결 누적 수는 해당 환경의 상태 기록을 확인해야 합니다. 기능 구현 자체가 미래 모의 성과나 실계좌 수익성을 입증하지 않습니다.

## 검증

`tests/test_operational_review.py`는 새 완료 실행의 자동 발견, 과거 기준 시각의 원본 복원, 휴장 시 시세·체결 시각 보존, 개인정보 제외, 자연어 초안의 읽기전용 동작, 실험 미관측 상태, 차트 수집의 미래·누락·잘못된 날짜·빈 응답 제외, overlay 자료 보존과 선택 기능 실패의 내구성 기록을 외부 API 없이 확인합니다.

`.github/scripts/investment_review_regression.py`는 360/390/430/1440 화면에서 차트·원래 차단 이유·모의 상태·실험 카드·자연어 초안·모호한 조건 보류·XSS 방지·과거 재생·잘못된 조회 후 이전 화면 제거를 확인합니다. 모바일 화면의 실제 너비가 강제로 확대되지 않는지도 검사합니다.
