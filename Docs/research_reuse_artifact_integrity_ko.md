# 재사용 연구의 보고서 원본 보존

## 실제 재개 실패

2026-10-22 미국 daily 연구의 네 번째 시도는 원래 17:45 세션에서 23:15:31.471886 KST에 시작했고, 23:16:02에 `Recovery lineage reused research changed`로 실패했다. 실행 코드는 `aec7f290`이며 신규 종목 연구 전에 계보 검증에서 중단됐다. 오늘의 원래 4회 한도는 모두 사용됐으며 실패를 취소하거나 재실행하지 않았다.

부모 `20261022T192108_local-scheduler-us-full`과 재개 결과 `20261022T221611_local-scheduler-us-full`을 직접 대조했다. 재사용한 22종목 모두 `investment_review_html`의 내용만 달랐고 artifact key 집합, 분석 JSON, 최종 상태, Markdown 보고서, 실행 계약과 다른 artifact는 원본과 같았다. 종목 판단·분석일·거래일·시작/완료 시각, 원래 사용량·metrics·duration 및 행/전체 재사용 영수증과 부모 manifest 해시도 같았다.

실패 분기는 전체 artifact 해시의 비교였다. 예를 들어 AAPL의 원본 HTML SHA-256은 `b32011a63500732ae98648468e53c0d2c340d6bc2d42300458d2d0b985762ef0`인데 재개 결과는 `3ebae5e2c833220dbe4207011a6d1f80a5b3f9312ba643335100c6691d0f99a9`였다. 실패한 원본과 시도 기록은 변경하지 않는다.

## 원인과 수정 범위

full 연구의 후처리는 성공한 모든 종목의 통합 HTML을 현재 시각과 현재 성과 DB로 다시 만들었다. 여기에는 원본의 해시를 검증해 복사한 재사용 종목도 포함됐다. 실제 변경 시각은 세 번째 시도의 22:45~22:46 후처리 구간과 일치했고, 날짜 문자열만 제외해도 내용 차이가 남았다.

`research_reuse`가 있는 종목은 통합 보고서 갱신 함수에서 DB 조회 전에 반환해 복사된 HTML을 그대로 보존한다. 원본에 HTML이 없었던 과거 형식도 새 artifact를 임의로 추가하지 않는다. 이번 실행에서 새로 성공한 종목은 기존대로 새 통합 보고서를 만든다. 복사된 HTML에 현재 성과 DB 내용이 새로 반영됐다고 표시하지 않으며, 이는 원본 연구의 보고서다.

별도 오프라인 재현에서는 execution 갱신을 켠 full 재개의 체크포인트 경로도 같은 원본을 손상시켰다. 현재 시세 조회가 실패한 경우에도 복사된 analysis와 HTML을 바꾸고 두 artifact key를 추가했다. 이 경로는 실제 네 번째 시도와 구분한다. 당시 예약 연구는 execution 갱신을 끈 상태였다.

체크포인트 갱신 함수도 재사용 행을 제외하고 신규 연구 행만 처리한다. 모두 재사용이면 조회나 쓰기 전에 빈 결과를 반환한다. 전체 연구 종목 집합·coverage·결정 bundle 입력은 유지하며, 재사용 행에 이번 체크포인트를 새로 수행한 것으로 표시하지 않는다. 다음 독립 일반 overlay는 원래 bootstrap이 새 행을 구성하므로 모든 대상의 현재 시세 갱신을 계속한다. 원래 계보 검증기는 바꾸지 않는다.

원래 artifact 전체 해시와 key 집합, 판단·시각·사용량·선정·계보의 검증은 유지한다. HTML만 예외 처리하거나 과거 영수증을 다시 쓰지 않는다. 따라서 이미 후처리로 달라진 세 번째 시도의 재사용 HTML은 계속 거절된다. 앞으로 유효한 원본을 재사용하는 경로에서 같은 문제가 생기지 않도록 하는 수정이다.

## 검증과 한계

외부 API와 모델 호출 없는 fixture로 재개 복사, 신규 성공/실패 혼합, full 후처리와 다음 엄격한 계보 로드를 연결해 검증한다. execution 갱신 활성/비활성, 원본 HTML 유무, 신규 전부 성공/잔여 실패의 조합을 포함한다. 재사용 HTML과 원래 영수증은 같고 새 성공 종목의 통합 보고서는 정상 갱신돼야 한다. 원본 HTML 변조와 다른 필수 artifact 변조는 계속 거절해야 한다. 다음 일반 overlay의 전종목 처리와 원본 보존, 모두 재사용일 때 추가 조회가 없는 경계도 확인한다. 실제 테스트 수치, 최종 커밋 CI와 배포 결과는 별도 검증 기록으로 확인한다.

관련 7개 테스트 파일의 165개가 통과했고, 마지막 일반 overlay fixture를 강화한 후 해당 11개 검사가 통과했다. 독립 메모리 검증 7개와 Ruff·diff 검사도 통과했다. 완전히 완료된 재개 결과는 실제 엄격한 선택기와 일반 bootstrap을 거쳐 전종목을 갱신하는지 확인한다. 부분 실패의 helper 검사는 완전한 정상 기준선으로 승격됐다는 증거가 아니다. 이 수치는 로컬 검증이며 최종 head CI나 운영 재개 성공을 대신하지 않는다.

이 실패는 PR #439의 신규 성공 0건 후처리 생략 동작에 도달하기 전에 발생했다. 따라서 네 번째 시도를 그 변경의 운영 성공 증거로 집계하지 않는다. 원래 4회 예산·60분 간격·제한 재분석 슬롯·승인 시각·원장은 유지한다.

DELL·ETN 등의 원천 일봉 오류, 정상 전략 BUY·SELL 체결, 국내 별도 왕복, 실제 비용·정산·반복 표본은 별도의 미충족 기준이다. 이 변경으로 해결됐다고 표시하지 않으며 실계좌 주문과 실제 투자 자동 전환은 계속 비활성이다.
