# 보고서 근거 봉인과 차트 가격 수준 표시

2026-10-26. 정상 연구·승인·증권사 모의 체결·실제 비용을 서로 다른 완료 조건으로 유지한다. 이 변경은 주문 권한, 원래 판단, 허용 금액·횟수, 시세·계좌의 유효시간을 바꾸지 않는다. 실계좌와 자동 실투자 전환은 비활성이다.

## 보고서의 첫 미충족 조건

새 기능은 `python -m tradingagents.work prepare --surface kr --report-context-v1`처럼 기존 준비 명령에 명시적으로 붙이는 선택 기능이다. 미국은 `--surface us`를 사용한다. 이 명령은 실제 운영에서 packet과 상태를 준비하는 명령이므로 읽기 전용 진단으로 실행하지 않는다. 기존 생산·보고 담당자가 원래 준비·발행·ACK 절차 안에서 선택해야 한다. 이 문서의 작성과 검사에서는 실제 운영 상태·보고서·ACK를 만들거나 발행하지 않았다.

기본 KR12/US13, 원래 프롬프트·SKILL·작업 manifest는 유지한다. 선택한 새 계약만 KR13/US14를 사용한다. 기존 pending, 원본 보고서의 바이트·해시·ACK와 공개 사이트의 동일 바이트 전달을 보존한다. 새 코드의 설치를 다음 정상 보고서의 실제 적용·수령 완료로 표시하지 않는다.

새 context는 자료, 원래 판단과 현재 실행 준비를 구분하고 첫 미충족 조건·정적인 담당 역할·다음 증거 조건을 제공한다. 종목별 필수자료는 성공 run이나 요약의 COMPLETE 문구로 추정하지 않는다. 선택한 원래 analysis의 SHA·시장·거래일·원래 시작/완료 시각·정형 판단·기존 Tool 심사를 현재 thesis SHA/clock에 묶는다. 누락·시점 역전·다른 원본·기본 fallback은 미확인 또는 해당 차단 사유로 남긴다. 원문의 명시적인 WAIT를 파싱 실패나 BUY로 바꾸지 않는다.

공개 context는 계좌·수량·보유 역할·소유자·실제 비용·정산 원문을 제공하지 않는다. 실제 주문·체결·비용은 비공개 운영실에서 별도로 확인해야 한다. 공개 보고서는 승인 영수증이 아니며 새 버전의 top actions 상한은3개다. 전체 종목 커버리지와 원래 행동 계약은 유지한다.

## 이전 보고서와 ACK의 결합

비교는 해당 시장의 정확한 마지막 ACK, 자체 surface revision, immutable packet/report, 보고서 해시·계약·시각과 결합한다. 최신 포인터를 과거 보고서의 권한으로 사용하지 않는다. `generated <= published <= acknowledged <= comparison cutoff`를 확인하고 다른 시장·다른 workflow hash·미래 ACK·잘못된 경로·원본 변조를 미확인으로 닫는다. 자체 revision 증거가 없는 과거 ACK도 새 비교에서 미확인이다. 과거 상태를 소급 수선하지 않는다.

동일 upstream은 이전 ACK context를 다시 봉인하기 전에 RESUME/NOOP로 판단한다. 자신의 ACK 때문에 event ID가 계속 바뀌는 발행 반복을 만들지 않는다. 새 보고서는 packet에 봉인된 context를 정확히 복사해야 하며 LLM이 임의로 수치·비용·완료 판정을 추가할 수 없다. 새 버전의 외피와 source summary도 검사해 context 밖에 private 자료를 넣는 우회를 거절한다. 공개 사이트는 검증된 보고서를 그대로 복사하며 사후 삭제·재해시로 개인정보 검사를 대신하지 않는다.

## 차트의 가격 이름과 원본 수준

실제390px AAPL 및1440px 국내 화면에서는 여러 가격 수준 이름이 겹쳐 봉을 가렸다. 가격선과 수치를 제거하는 방식으로 해결하지 않는다. 기본 화면은 이름·수준 축 라벨을 숨겨 봉을 읽고, 별도 표에서 중복을 포함한 모든 원래 수준의 이름·정확한 가격·스타일·출처·시각을 확인한다. 없는 출처나 시각은 추정하지 않는다.

각 차트의 명시적 체크박스로 그 차트의 이름을 표시할 수 있다. 키보드와 고유 label/controls 연결을 제공하고, 새 조회 이후 제거된 차트 핸들에는 토글을 적용하지 않는다. 작은 화면의 표는 자체 가로 스크롤을 사용하며 페이지 전체를 밀어내지 않는다. 0건·0회 같은 단위는 분리하지 않는다. 선의 가격·색·스타일, 원래 수준과 시간 필터, VWAP 근사 구분과 주문 승인 경계는 유지한다.
