## 수정

1. 사전 정리: 작업 10분/단계 5분 제한, 시작 및 삭제 대상 로그, 비대화형 PowerShell과 사용자 프로필 미실행, 최상위 reparse point 거부.
2. 일일 분석 및 Work Pages 빌드: Windows commit/물리 메모리/디스크 여유 검사. 기존 로컬 미반영 자원 검사 코드를 재사용하고 부족·회복·경계값 회귀 테스트를 추가했다.
3. Work 보고서의 사용자 입력은 환경변수로 전달한다. 따옴표 등 입력이 실행할 Python 코드로 해석되지 않도록 했다.
4. 장기 보관 정리는 내부 junction/symlink를 재귀 순회하거나 외부 파일 속성을 변경하기 전에 거부한다. 외부 파일 보존을 실제 Windows junction으로 검증한다.
5. 최신 OHLCV의 0원 가격 및 일중 범위를 벗어난 시가/종가를 거부한다. 거래량 0은 허용하며 미래의 불량 데이터는 과거 분석에 영향을 주지 않는다.
6. Pages 빌드는 보관 실행별 진행률과 소요 시간을 남겨 생성 단계의 정지와 지연을 구분할 수 있도록 한다.
7. CI가 uv.lock을 무시하고 최신 패키지를 임의 설치하던 문제를 수정한다. lock에서 제약을 추출해 Telegram/PDF 선택 의존성까지 테스트하므로 의존성 PR이 실제 변경 버전으로 검증된다.
8. `TRADINGAGENTS_PAGES_RUNNER_LABELS` JSON 배열로 Work Pages 전용 러너를 지정할 수 있다. 미설정 시 기존 Windows 러너를 사용한다. 이 PC에는 별도 작업 폴더와 `tradingagents-pages` 라벨만 사용하는 러너를 구성해 긴 분석 작업과의 대기열 충돌을 줄인다. CPU/메모리는 같은 PC 자원이므로 자원 검사는 유지한다.
