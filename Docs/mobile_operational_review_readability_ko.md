# 모바일 운영 표와 진행 상태의 가독성

2026-10-26. 보관 검토 화면의 실제 폭별 fixture를 다시 읽어, 모바일의 다섯 열 표가 글자 단위로 좁게 줄바꿈되는 문제를 확인했다. 표 바깥 페이지의 넘침이 없다는 기존 검사는 읽을 수 있는 열 폭을 보증하지 못했다.

공통 운영 표는 세 열 이상일 때 열당 9rem의 최소폭을 유지하고 표 영역 안에서만 가로로 이동한다. 한글은 단어 단위 줄바꿈을 우선한다. 좌우 이동 안내와 키보드 포커스를 제공하며, 두 열 표는 원래 자동폭을 유지한다. 숫자·원문·열 순서·비용 계산·주문 동작은 바꾸지 않는다.

종목과 기준 시각 입력을 접어도 진행·실패 안내와 선택 원본 시각은 계속 보인다. 화면 첫 부분의 정상 체결·비용 요약과 보관 차트 조회 상태는 각각 확인한다.

검사는 360/390/430/1440px에서 운영 표를 차트 라이브러리 내부 레이아웃 표와 구별한다. 셀 최소폭, 표 안의 실제 좌우·키보드 이동, 페이지 넘침 없음, 두 열 표 유지, 넓은 표가 들어맞는 데스크톱에서 불필요한 스크롤 없음, 접힌 설정과 독립된 진행·timeout·오류 안내를 확인한다. 첫 잘못된 테스트 선택자 실패도 별도 원본으로 보존했다.

이 문서는 화면 가독성 계약이다. 최종 코드의 CI와 실제 8766 서버의 국내·미국 조회·차트·상태 검증은 배포 영수증으로 따로 판단한다. 화면 검사나 읽기 성공은 정상 전략 체결·수익·실투자 준비 완료의 증거가 아니다.
