# 기술 지표 최소 입력 계약

기존 5년 수집창과 stockstats 계산식은 유지한다. 이 계약은 관측치가 부족한
초기 출력이 완전한 기간의 지표로 표시되는 것을 막는다. EMA·SMMA의 수렴이나
과거 전체 이력과의 동등성을 보증하지 않는다.

| 지표 | 필요한 유효 일봉 수 |
|---|---:|
| close_50_sma / close_200_sma | 50 / 200 |
| close_10_ema | 10 |
| macd | max(단기 EMA 기간, 장기 EMA 기간), 기본 26 |
| macds / macdh | 위 기간 + signal 기간 − 1, 기본 34 |
| boll / boll_ub / boll_lb | 기본 20 |
| vwma | 기본 14 |
| rsi / atr / mfi | 기본 14기간 + 전일 가격 관측치 1개 = 15 |

기본 기간은 설치된 stockstats의 설정을 읽는다. ATR의 첫 행 seed를 완전한
전일 종가가 있는 TR로 세지 않고, RSI·MFI의 첫 행 방향 seed도 관측으로
세지 않는 보수적인 최소 입력 계약이다. 계산 자체를 재초기화하지는 않는다.

- 날짜를 분석 기준일까지 로컬 필터링한 뒤 중복을 제거한다. 미래·누락·잘못된
  날짜는 관측 수와 계산에 기여하지 않는다. 지표가 사용하는 가격·수량의
  누락 및 비정상 값은 실패한다.
- 한국·미국 주식은 기존 거래소 달력과 한국 보완 휴일을 사용해 최초 관측일부터
  기준일까지 누락 거래일과 비거래일 일봉을 검사한다. 다른 자산의 달력을 추정하지 않는다.
- bulk 내부 초기 행은 명시적인 N/A 상태다. 요청된 단건이나 출력 기간에 해당
  행이 포함되면 `InsufficientIndicatorHistoryError`로 실패한다. 긴 lookback이
  warmup 부족 구간을 포함해도 정상 보고서로 포장하지 않는다.
- 주말·휴일만 요청해서 실제 지표 관측값이 0개인 출력도 성공으로 처리하지 않는다.
  유효한 관측값과 함께 표시되는 비거래일의 N/A는 허용한다.
- 이 오류는 날짜별 재조회와 상위 공급자 fallback에서 재시도하지 않으며,
  에이전트 도구까지 전파된다. telemetry의 결과는 `error`다.
- 충분한 이력은 기존 전체 계산창의 값과 동일하다. RSI의 오래된 상승 후 횡보
  사례에서 전체 이력 값 100과 최근 255행 값 50의 차이를 보존하는 회귀 테스트로
  임의 이력 축소를 차단한다.

검증은 Mock/fixture 전용이다. 실제 증권사 체결, 실데이터 완전성, 배포 완료를
증명하지 않는다. 상장일 메타데이터, 공급자 경로, 계좌와 연구 승인은 이 변경 범위에 없다.
