기준일: 2026-10-22. 이 문서는 공식 자료 비교, 이번 감사 결과, 아직 충족하지 못한 검증 기준을 기록한다. 사전 검증은 병합·배포 또는 체결 완료를 뜻하지 않으며 배포 확인과 운영 체결은 원본 기록으로 따로 확인한다. 계좌번호·인증정보는 포함하지 않는다.

## 목표와 보존 조건

원래 연구 판단, 계좌 소유권, 잠금, 원장, 승인 범위·기한, 주문 한도, 자료·공시·회고 메모리의 시점 검증을 보존한다. 기존 `create_llm_client`와 정형 의사결정 검증을 사용한다. 위험 축소 매도는 신규 매수와 구분한다. 체결 목표를 위해 WAIT를 BUY로 바꾸거나 한도·승인 기한을 늘리지 않는다. 실계좌 주문 비활성과 실제 투자 자동 전환 금지를 유지한다.

## KIS 조회에서 별도로 지킬 계약

- 해외 모의 체결조회는 `PDNO=""`, `OVRS_EXCG_CD=""`, `SLL_BUY_DVSN="00"`, `CCLD_NCCS_DVSN="00"`을 사용한다. `ODNO` 직접 검색은 지원하지 않으므로 빈 값으로 조회하고 반환 기록을 로컬에서 대조한다.
- 국내 15건 한도 이후와 해외 연속 페이지를 모두 읽는다. 반복 커서·페이지 한도 도달·중간 오류는 조회 미완료이며 정상 빈 결과와 다르다.
- 공식 [해외 미체결 샘플](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/inquire_nccs/inquire_nccs.py)은 `env_dv` 인자와 별개로 TR ID를 고정하고, 중간 오류 시 누적 자료를 반환하기도 한다. 샘플을 그대로 복사했다는 이유로 모의 환경·전체 조회 완료를 인정하지 않는다.
- 계좌 잔고만으로 특정 전략 체결을 만들지 않는다. 증권사 보고와 해당 승인·주문 원장의 귀속이 일치해야 한다.

공식 KIS 샘플 `2077773a69a428daf63e148182511f068cc45de3`의 [국내 모의 잔고 필드](https://raw.githubusercontent.com/koreainvestment/open-trading-api/2077773a69a428daf63e148182511f068cc45de3/examples_llm/domestic_stock/inquire_balance/chk_inquire_balance.py)는 전일·금일 제비용 및 차기·가수도 정산금액을 제공하지만 계좌 집계다. 정상 전략·별도 검증·기존 보유분에 임의 배분하지 않는다. [국내 기간매매손익](https://raw.githubusercontent.com/koreainvestment/open-trading-api/2077773a69a428daf63e148182511f068cc45de3/examples_llm/domestic_stock/inquire_period_trade_profit/inquire_period_trade_profit.py)과 [해외 기간거래](https://raw.githubusercontent.com/koreainvestment/open-trading-api/2077773a69a428daf63e148182511f068cc45de3/examples_llm/overseas_stock/inquire_period_trans/inquire_period_trans.py)의 공식 코드에는 실전 TR만 확인된다. 모의 지원을 입증하지 못했으므로 허용 API에 추가하거나 실전 호스트로 우회하지 않는다.

확정 비용을 향후 수입할 때에는 원주문·통화·명세 행·개정 ID 및 원문 해시를 연결한 추가 전용 증거가 필요하다. 비용의 명시적 0과 누락을 구분하고 거래일·정산일·발행·확정·수집 시점을 별도로 보존한다. 중복은 한 번만 반영하며 정정은 기존 행을 덮어쓰지 않고 연결한다. 모든 관련 체결의 수량·대금·귀속·비용 구성·정산을 기준일까지 대조할 수 있을 때만 확정 순손익으로 승격한다. 현재 구현에는 이 승격 증거가 없고 `actual_cost`와 `net_pnl`은 null이다.

비용 체크포인트 검증 강화의 별도 관련 검사 177개가 통과했으며, 이는 실제 비용 명세 확보·정산 대조·순손익 확정 완료와 구분한다.

## 증거의 의미와 실투자 전환 경계

Mock 통과는 지정한 입력에서 코드가 계약을 지킨다는 증거다. 실제 API 응답은 해당 시점 조회·접수·체결의 증거이며, 정상 전략 귀속은 원본 연구와 승인 원장을 추가로 대조해야 한다. 배포는 실행 버전 확인, 운영 완료는 장중 관측과 증권사 체결, 성과 완료는 비용을 포함한 재계산으로 각각 입증한다.

[Alpaca 모의 설명](https://docs.alpaca.markets/us/docs/paper-trading)은 시장 충격·지연 슬리피지·대기열·규제 비용 등의 미재현을 명시한다. 이는 모의 성과의 한계를 평가할 참고이며 KIS가 같은 방식으로 작동한다는 증거는 아니다. KIS에서 확인한 범위와 아직 재현하지 못한 조건을 따로 표시한다.

국내·미국 정상 전략 체결, 국내 검증 왕복, 실제 순비용, 반복 표본, 장애 복구의 운영 증거가 아직 부족하다. 구현·테스트 또는 단회 왕복을 실투자 준비 완료로 표시하지 않는다. 실계좌 주문은 계속 비활성이며, 본 문서의 어느 통과 결과도 실제 투자 자동 전환이나 별도 승인 없는 실계좌 활성화를 허용하지 않는다.
